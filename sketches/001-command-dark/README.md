# Variant 001 · 命令优先（深色紧凑）

## Design stance
以"搜索即用"为核心：开发者习惯用键盘驱动一切，工具不是被"浏览"的，而是被"呼出"的。

## Key choices
- **布局**：顶部全局搜索 + 分类 Chips + 密集工具网格 + 右侧检查器（三栏工作台式）
- **交互**：点击工具 → 右侧检查器实时展示详情与在线演示；双击或"打开工具"直接运行；Ctrl+K 聚焦搜索
- **配色**：深蓝黑底 + 青绿色强调色（`#2dd4bf`），终端式色彩逻辑
- **字体**：IBM Plex Sans / Mono，代码工具的专业感
- **密度**：紧凑，一屏容纳 21 个工具

## Trade-offs
- 强于：开发者、重度用户、键盘流，信息密度高
- 弱于：对鼠标流 / 普通用户有学习成本，视觉上"不够亲切"

## Best for
面向开发者的效率工具箱（uTools / Rubick 路线），Electron / Tauri 实现时最贴近原生桌面观感。
