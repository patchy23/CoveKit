# Variant 002 · 内容优先（明净浅色）

## Design stance
把工具箱当作一个"工具商店"来浏览：分类清晰、卡片信息完整，普通用户零学习成本。

## Key choices
- **布局**：左侧分类导航（带计数）+ 顶栏搜索 + 大卡片网格（网格/列表双视图）
- **交互**：点击卡片弹出工具弹窗（含在线演示）；收藏星标；最近使用快捷条；浅/深主题一键切换
- **配色**：暖橙强调色（`#f0562c`）+ 米白底，苹果式柔和
- **字体**：Inter，干净现代
- **密度**：宽松，卡片带描述与标签，扫读性好

## Trade-offs
- 强于：大众用户、通用场景，导航清晰、亲和力强
- 弱于：大屏下信息密度偏低，专业开发者可能觉得"绕"

## Best for
面向普通用户的通用工具箱，或需要同时服务新手与老手的场景；浅色主题适合办公环境。
