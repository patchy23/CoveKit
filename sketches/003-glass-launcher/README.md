# Variant 003 · 沉浸玻璃（悬浮启动器）

## Design stance
把工具箱做成一款"悬浮于桌面之上"的启动器：动态光晕背景 + 毛玻璃面板 + 底部 Dock，第一眼就抓人。

## Key choices
- **布局**：居中玻璃面板（搜索 + 分类 + 工具网格）+ 底部 Dock（常用工具 + 悬停提示）+ 顶栏时钟胶囊
- **交互**：点击工具从 Dock 上方弹出启动器弹窗（含在线演示）；⌘K 聚焦搜索；Esc 关闭
- **配色**：深空蓝底 + 三团动态渐变光晕 + 青蓝渐变强调色，玻璃折射质感
- **字体**：Space Grotesk + Noto Sans SC，科技感
- **密度**：适中，卡片圆角大、留白足

## Trade-offs
- 强于：视觉冲击力、品牌感、演示/发布场景
- 弱于：毛玻璃在低配机器上有性能开销；浅色环境适配需额外设计；偏"展示型"

## Best for
想要差异化视觉、面向 C 端用户的产品，或作为启动器/主界面（Spotlight 式）的定位。
