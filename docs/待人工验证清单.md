# patchyBox · 待人工验证清单

> 唯一维护「助手跑不出证据、必须人工或真机执行」的验收项。用户 2026-09-16 裁决：这类项集中登记在本文件，**不卡任务书进度**。
> 活动方案只链接本文件，不重复列表；**本文件的条目不作为任务书或批次收口的阻塞条件**。权威分工见 [17-文档组织与批次](standards/17-文档组织与批次.md)。

## 用法

- 每条给出：验证什么、归属、前置与步骤、预期，以及「做完拿到什么 / 不做的影响」——后两列只用于排优先级，不改变「不阻塞任务书」的口径。
- 完成后在同一改动中给出必要结果；活动任务写已有方案，历史任务无需重开或回填台账，然后移除待办行。关键结果可用提交正文或必要验收摘要追溯。
- 凭证现场输入、测完即弃，不写进仓库。
- `☐` 待验证；失败时说明原因，完成后退出待办，不同时要求保留完成行与删除行。
- 后续批次产生的人工项（如 L2 前端向导走查、L5 双平台测试）由当批执行者按同样格式追加，不预先留空条目。
