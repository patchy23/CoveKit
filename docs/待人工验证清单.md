## 用法

- 每条给出：验证什么、归属、前置与步骤、预期。做完把结果写回对应批次文档（补证据）与[进度台账](进度台账.md)，然后删掉本行——本文件不留历史，历史在批次文档与台账。
- 凭证现场输入、测完即弃，不写进仓库。
- `☐` 待验证；完成后改成 `☑ 2026-09-xx 通过（证据：…）` 或 `✗ <原因>`。
- 后续批次产生的人工项（如 L2 前端向导走查、L5 双平台测试）由当批执行者按同样格式追加，不预先留空条目。
