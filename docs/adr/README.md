# 架构决策记录（ADR）

> **常青层**。这里放**跨批次、推翻会伤筋动骨**的决定。
> 判断标准：如果这条决定被后来的人改掉，会导致大量返工、数据不兼容或安全边界失守，它就属于 ADR；否则留在批次文档里即可。

## 规则

1. **一经采纳，正文不再修改**。要改就新写一条 ADR，在里面写明「取代 ADR-000X」。
2. 一条 ADR 只回答三件事：**当时的处境**、**选了什么**、**这样做换来什么、代价是什么**。
3. 状态取值：`已采纳` / `已取代（由 ADR-XXXX 取代）` / `已废弃`。
4. 文件名：`ADR-<四位序号>-<中文标题>.md`，序号全局递增，不复用。

## 模板

```markdown
# ADR-0001 · <决定的一句话标题>

- 状态：已采纳
- 日期：YYYY-MM-DD
- 批次：<批次号，如 arch-202609-001>

## 处境

<是什么问题逼着我们做决定；不做会怎样。>

## 决定

<选了什么，一句话说死。>

## 代价与边界

<换来了什么、放弃了什么、什么情况下需要重新审视。>
```
