# ADR-0001 · 禁用 shell 插件，系统能力走官方插件或自研

- 状态：已采纳
- 日期：2026-09-14
- 批次：arch-202609-001

## 处境

需要执行命令或读写系统资源时，最省事的做法是引入 `tauri-plugin-shell`。但它把任意命令执行的能力暴露到前端一层，与本项目「内置受信工具集合、插件按公开契约协作」的定位冲突：一处前端漏洞或误用即可升级为任意代码执行。

## 决定

禁用 `tauri-plugin-shell`。系统能力只走官方插件或本项目自研模块；确需执行外部命令时，在插件后端按白名单实现，入口不接受前端传入的任意命令串。

## 代价与边界

每个新系统能力都要自己写实现与权限校验，开发成本更高、可复用性更低。重新审视的条件是官方出现粒度更细、默认拒绝的等价能力；在此之前不得以「只是读个文件」「只是调个命令」为由引入。
