# ADR-0005 · 文档三层与批次号组织

- 状态：已采纳
- 日期：2026-09-14
- 批次：docs-202609-001

## 处境

文档混放会让「哪些是常青规则、哪些是一次性任务、哪些是已定决策」无法区分；新会话往往被迫全量读取，上下文成本高且容易把过期批次指令当成现行规范。

## 决定

文档分三层：常青规范 `docs/standards/`、跨批次决策 `docs/adr/`、批次任务 `docs/batches/<批次号>/`。常青文档用中文名；批次目录命名 `领域-年月-编号-简述`。进度只在 `docs/进度台账.md`（唯一权威视图），范围与用户裁决只在 `TODO.md`，两者不互相搬运。

## 代价与边界

每份新文档都要先定层，不能随手放；批次结束后其文档降为历史记录，不再作为现行规范被引用。文档体量受 `scripts/check_doc_budget.py` 约束，超线触发职责审查，不为字数机械拆分。
