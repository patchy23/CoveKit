# ADR-0003 · Rust 规范检查走棘轮而非 clippy deny

- 状态：已采纳
- 日期：2026-09-14
- 批次：arch-202609-001

## 处境

存量代码有大量规范违规（`unwrap`、裸 `as`、代价不明的 `clone`）。直接开 `-D warnings` 作为合入门禁，会让任何一次改动都因既有违规无法提交，实际上等于门禁不可用。

## 决定

规范检查走棘轮：`scripts/check_rust_rules.py` 维护违规基线，只许下降不许上升，涨一即失败；不把 clippy deny 提为合入红线。运行期禁 `unwrap`/`expect`、`unsafe` 必带紧邻 `// SAFETY:` 论证等硬要求仍由规范与评审承担。

## 代价与边界

新代码的违规不会被立刻拦住，只能靠评审与棘轮逐次收敛；基线数字本身不是目标，不得为了降低数字而删除有意义的覆盖或提高例外登记。重新审视的条件是存量违规收敛到接近零。
