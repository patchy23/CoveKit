# 18 · 重构与搬移验证（独立复核配方）

> 本文原为 AI 助手侧技能库中的项目知识，2026-09-13 迁入仓库，作为项目自有开发手册的一部分。正文未改写（仅同步文档路径与目录规范）。

适用：把大文件拆成多域、把实现搬进新模块、改公共契约等「声明行为零变化」的改动——产物由子 agent 交付时尤其必须走。

原则：**子 agent 的自报（行数、相等、全绿）不是证据**。证据 = 集成者在已提交树上跑出的输出 + 脚本比对结果。

## 1. 公开面逐一相等（对 `git show HEAD:<file>` 比对）

最该防的是「返回面漏 key / 多 key / 改名」。不要肉眼看，脚本比对：

```python
import re, subprocess, pathlib
path = "src/plugins/<owner>/<file>.ts"
old = subprocess.run(["git", "show", f"HEAD:{path}"], capture_output=True, text=True).stdout
new = pathlib.Path(path).read_text(encoding="utf-8", newline="")

def surface(src: str) -> set[str]:
    body = src.split("return {", 1)[1]                 # composable 门面
    return set(re.findall(r"(?m)^\s{2,}([A-Za-z_$][\w$]*)[,:]", body))

print(len(surface(old)), len(surface(new)), surface(old) ^ surface(new))
```

- composable：抓 `return {` 块的键名（实测一次四处拆分核对出 77 键逐一相等）
- 纯 TS/模块：比对 `export` 名集合
- 有差异要么补齐，要么在报告里逐条列出并说明理由，禁止「看起来一样」

## 2. 消费方 import 覆盖

用 `search_files` 找全部 `from '@/plugins/<owner>/...'` 的具名导入，逐个确认门面已再导出（`export { x } from './domain/...'`）。只有这一步过了，「消费方零改动」这句话才成立（实测 14 处 import 名全部由门面再导出）。

## 3. 接入「孤儿模块」前先对照活跃实现

按行数红线抽出、但从未被接入的模块常有多个（同一职责的旧副本）。接入顺序固定：

1. 以**活跃实现**为行为基线（谁被 `index.vue` / 上层消费，谁就是基线）
2. 逐条枚举活跃侧**较新的行为**（失败提示是否可见、是否有关联清理、错误分支是否齐全、时间戳归属、迁移/兼容分支），确认已搬进新域
3. 典型旧副本缺陷：`catch` 静默吞迁移失败 → 用户看到「数据消失」；不清理关联状态 → 删条目留孤儿工作区/页签

红线：**不得用旧副本覆盖新修复**。重复实现收敛成一份时，删掉的是旧副本的旧行为，不是活跃侧的新行为。

## 4. 新增测试范式先确认

仓库既有测试可能只覆盖纯函数（例如没有任何 `vi.mock('./ipc')` 先例）。为 composable/组件引入 IPC mock 属于**新测试范式 = 结构性改动**，先提议给用户再写；确实做不了的验收项，在计划书与完成报告里写明「未做 + 理由」，不得静默跳过。

## 5. 门禁自己跑一遍

不采信子会话的 `pnpm test/lint/build` 输出，在提交树上重跑：`pnpm test` / `pnpm lint` / `pnpm build`（含 vue-tsc）/ `pnpm format:check` / `node scripts/check_frontend_deps.mjs`；动 Rust 另加 `cargo fmt` / `cargo clippy -- -D warnings` / `cargo test --test source_rules`。

## 6. 过期后台报告判定

后台批次报失败时先判时点：进程启动于修复提交之前 → 报告过期，按过期处理并在报告中说明；然后用**已提交树**重跑它跑过的同一条命令取值。不要在已修好的代码上「复修」。

## 7. 证明新增的门禁 / 契约测试不是空转

新写的检查器、契约测试、源码扫描断言很容易恒真（扫不到东西也绿）。**提交前做一次负例实验**：临时把被测对象改坏或抽掉（撤一条注册行、删一个导出名），跑该测试，确认它**变红且报出正确的差异数字**，再恢复原状并复跑确认转绿——没有变红过的检查器不算证据（实测形态：抽掉清单里一行后，比对用例报出「声明侧 N 个 vs 清单侧 N-1 个」）。实验后必须与临时改动走同一条路径恢复，并重跑全量测试，避免把实验残留提交上去。
