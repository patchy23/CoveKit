## 6. SSH 远程管理（旗舰模块）

### 6.1 产品目标

SSH 不只是一块终端，而是一台服务器的本地工作区。它要替代作者日常最常打开的 SSH/SFTP/基础运维工具，但不变成堡垒机或自动化运维平台。

### 6.2 主页面布局

#### SSH-001 工作区结构（P0/P1）

```text
┌─服务器列表 220px──┬──────────────────────────────────────────────────────┐
│ 搜索          ＋  │ 生产服务器 ● | 测试机 ● | …                         │
│ [导入 SSH Config] ├──────────────────────────────────────────────────────┤
│ ▾ 生产环境 (3)    │ 终端 | 文件 | 监控 | 服务 | 进程 | Docker | 隧道    │
│   ● 主站          ├──────────────────────────────────────────────────────┤
│   ○ 数据节点      │ 当前功能区                                           │
│ ▾ 测试环境 (2)    │                                                       │
│ ☆ 未分组          │                                                       │
│                   ├──────────────────────────────────────────────────────┤
│ + 添加服务器      │ host · user · 延迟 · 连接时长 · 最近活动             │
└───────────────────┴──────────────────────────────────────────────────────┘
```

调整点：

- 左栏从当前 180px 调整到默认 220px，并允许在 180–360px 间拖拽。
- 顶部为搜索框；`+` 打开新增菜单：添加服务器、导入 OpenSSH Config、从剪贴板识别 SSH 命令。
- 服务器按用户定义分组折叠，未分组置底。
- 列表项显示收藏、名称、`user@host:port`、状态点、最近延迟。
- 单击选中；双击连接；Enter 连接；右键菜单含连接、新窗口连接、编辑、复制 SSH 命令、网络诊断、删除。
- 同一 profile 可建立多个独立连接，沿用当前“名称、名称 2”的页签策略。
- 底部状态栏显示连接目标、握手延迟、连接时长、当前网络状态。

### 6.3 服务器配置

#### SSH-002 新建/编辑服务器（P0）

表单分为三个折叠区：

**基本信息**

- 名称，必填，默认从 host 推断。
- 分组，可新建分组。
- 标签，多选自由输入，如“生产”“国内”“个人”。
- 主机，支持 IPv4、IPv6、域名。
- 端口，默认 22，限制 1–65535。
- 备注。

**认证**

- 凭证选择器，支持密码或 SSH 私钥。
- “新建凭证”在 Vault 中创建，不把秘密保存到 SSH profile。
- “一次性认证”不落盘。
- 用户名以凭证中的用户名为主；若允许 profile 覆盖，界面必须明确显示覆盖关系。

**高级选项**

- 连接超时：3/5/10/30 秒。
- ServerAliveInterval：默认 30 秒；0 表示关闭。
- ServerAliveCountMax：默认 3。
- TCP keepalive：默认开启。
- 压缩：默认关闭。
- 首次进入目录：默认用户 home。
- 终端字符集：UTF-8；其他编码作为 P3。
- 跳板机：选择另一个 SSH profile，P2 实现。
- 代理：不设置 / SOCKS5，P2 实现。

底部按钮：

- `取消`：有修改时确认放弃。
- `测试连接`：执行握手和认证，返回 DNS、TCP、握手、认证各阶段耗时，不创建持久会话。
- `保存`：只保存配置，不自动连接。
- `保存并连接`：保存成功后连接；编辑已有在线 profile 时不影响现有会话，只影响新会话。

### 6.4 主机身份校验

#### SSH-003 known_hosts 与指纹（P0）

首次连接未知主机时必须弹窗：

- 主机和端口。
- 密钥算法。
- SHA256 指纹，可复制。
- `仅本次信任`、`保存并连接`、`取消`三个按钮。

已保存指纹发生变化时：

- 红色阻断弹窗，说明可能是服务器重装，也可能是中间人攻击。
- 显示旧指纹和新指纹。
- 默认按钮为“取消连接”。
- “替换指纹并连接”放在危险操作区，要求再次确认，不允许静默接受。

设置页增加“已知主机”管理：搜索、主机、算法、指纹、首次/最后连接时间、删除记录。

建议后端：

- `ssh_known_host_check(host, port, key)`。
- `ssh_known_host_trust({ host, port, algorithm, fingerprint })`。
- `ssh_known_host_list/delete`。

### 6.5 连接状态与错误

#### SSH-004 分阶段连接（P0）

连接状态必须区分：

`解析主机 → 建立 TCP → SSH 握手 → 校验主机指纹 → 认证 → 打开会话 → 已连接`。

错误使用稳定错误码：

- `DNS_RESOLVE_FAILED`。
- `TCP_TIMEOUT` / `CONNECTION_REFUSED`。
- `HOST_KEY_UNKNOWN` / `HOST_KEY_MISMATCH`。
- `AUTH_FAILED` / `KEY_PASSPHRASE_INVALID`。
- `SSH_PROTOCOL_ERROR`。
- `SESSION_CLOSED`。

错误面板提供：重试、编辑配置、网络诊断、复制详情。详情自动脱敏。

断线策略：

- 意外断线可自动重连，1/2/5/10/30 秒指数退避，最多 5 次。
- 用户主动断开不重连。
- 自动重连成功后新建 PTY；旧终端输出保留并插入“已于 xx:xx 重连”分隔线。
- 有文件传输或远程编辑保存时，不执行空闲自动断开。

### 6.6 终端

#### SSH-005 多终端与工具栏（P1）

连接级“终端”页内增加第二层终端页签：

```text
┌─────────────────────────────────────────────────────────┐
│ Shell 1 × | Shell 2 × | ＋     分屏  搜索  命令  重连  │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                       xterm                             │
│                                                         │
├─────────────────────────────────────────────────────────┤
│ UTF-8 · 120×34 · 2,000 scrollback · 已连接 01:25:43     │
└─────────────────────────────────────────────────────────┘
```

- `+` 新建 PTY；下拉可选普通 Shell、`sudo -i` 提示方式、已保存启动命令。
- 终端页签可重命名、关闭、关闭其他。
- 分屏支持水平/垂直两块，P2；第一版最多 4 个 pane。
- 搜索支持上一项、下一项、区分大小写、正则开关。
- 工具栏保留清空、重连，并增加复制全部、导出当前可见日志。
- 右键菜单保留全选/复制/粘贴；粘贴多行命令时弹出预览确认，可在设置关闭。
- URL 自动识别，`Ctrl+点击` 使用系统浏览器打开。
- 默认 scrollback 从 2,000 提升为可配置 2,000/10,000/50,000；切换工具页签不能丢失。
- 终端关闭前如有前台任务无法可靠识别，不强行拦截；关闭连接页签仍必须明确提示会结束全部会话。

建议后端继续复用：`ssh_terminal_open/write/resize/close/list` 和事件 `ssh://terminal-data`，新增：

- `ssh_terminal_signal(terminalId, signal)`，用于发送 SIGINT 等明确动作。
- `ssh_terminal_snapshot(terminalId)` 只导出当前缓冲区，不在后端永久记录终端内容。
- `ssh://terminal-closed` 携带 exit code 和关闭原因。

#### SSH-006 命令片段（P1）

这不是 Agent，也不是复杂编排，只解决重复输入命令。

- 终端右侧可打开 280px“命令片段”抽屉。
- 片段字段：名称、命令、分类、说明、危险级别、变量。
- 变量语法 `${name}`；执行前弹小表单填写。
- 危险级别：普通、需要确认、高危；高危命令必须完整预览并再次确认。
- 按钮：插入终端、执行、编辑、复制、收藏。
- “插入终端”只写入但不回车；默认推荐该方式。
- 片段数据保存在 SSH 插件本地库，可导入导出 JSON；不得保存密码变量。

### 6.7 文件管理

#### SSH-007 双栏文件管理（P1）

将现有单远端列表升级为本地/远端双栏，保留拖放上传：

```text
┌────────────── 本地 ──────────────┬────────────── 远端 ──────────────┐
│ ← ↑ →  路径                 刷新 │ ← ↑ →  /var/www            刷新 │
│ 名称        大小      修改时间   │ 名称 权限 所有者 大小 修改时间   │
│ ...                              │ ...                             │
├──────────────────────────────────┴─────────────────────────────────┤
│ 传输队列：2 进行中 / 1 等待     [全部暂停] [清除已完成]            │
└────────────────────────────────────────────────────────────────────┘
```

两侧工具栏：

- 后退、前进、上级、路径输入、刷新。
- 新建文件夹。
- 显示隐藏文件。
- 排序：名称、大小、修改时间。
- 本地侧“在资源管理器中打开”；远端侧“复制完整路径”。

文件操作：

- 从本地拖到远端上传，从远端拖到本地下载。
- 选中后使用方向箭头按钮传输。
- 多选、文件夹递归传输、删除、重命名、新建目录。
- 冲突策略：询问、覆盖、跳过、自动重命名；对当前队列可“全部应用”。
- 上传先写临时文件，完成后原子重命名，减少断线留下半文件。
- 任务中心显示速度、进度、剩余时间；断线后任务进入“等待重连”，不直接假成功。
- 可取消单项或全部任务；取消后清理临时文件。

#### SSH-008 远程编辑（P1）

- 双击不超过配置上限的文本文件打开编辑器，当前代码的 10 MiB 作为硬上限默认值。
- 打开时记录远端 mtime、size 和可选 hash。
- 保存前再次检查，远端文件已变化时提供：查看差异、覆盖、另存副本、取消。
- 状态栏显示编码、换行符、文件大小和是否已修改。
- 支持 UTF-8；检测非 UTF-8 时以只读方式打开并说明原因，其他编码 P3。
- 保存按钮和 `Ctrl+S`；关闭未保存编辑器时确认。
- 高权限路径保存失败时展示具体权限错误，不自动尝试 sudo 写入。

建议新增后端能力：

- `ssh_file_mkdir`。
- `ssh_file_stat`。
- `ssh_file_chmod`（P2，明确确认）。
- `ssh_file_transfer_cancel`。
- `ssh_edit_save` 增加 `expectedMtime` 或 `expectedHash` 乐观锁。

### 6.8 监控

#### SSH-009 真实采样与短期曲线（P1）

页面分三部分：

1. 顶部 CPU、内存、根分区、负载四张摘要卡。
2. 中部 CPU/内存、网络上下载速率两张最近 10 分钟折线图。
3. 底部磁盘分区表、网络接口表和系统信息。

要求：

- 当前网络累计值必须改成连续采样差值，输出真实 B/s。
- 采样间隔默认 2 秒，可选 1/2/5/10 秒。
- 只有页面可见且连接在线时采样；切走后停止定时器。
- 前端只保留最近 300 点，不落盘，不做长期监控平台。
- 单次获取失败不清空图表；连续 3 次失败显示“采样中断”和重试按钮。
- 显示 Linux 发行版、内核、运行时长、CPU 核数、主机名。

建议后端由 `ssh_monitor_get` 扩展为 `ssh_monitor_snapshot`，返回前后采样可计算字段；或由后端按 connection 维护上一采样值并直接给出速率。

### 6.9 服务、进程、Docker

#### SSH-010 systemd 服务（P1）

- 保留全部/运行中/已停止/失败筛选，增加名称搜索。
- 表头显示服务名、描述、状态、自启、最近状态变化、操作。
- 操作：启动、停止、重启、查看日志、设置/取消开机自启。
- 停止、重启、修改自启均需确认；启动可直接执行。
- 日志弹窗改为后端推送或增量读取，不每 2 秒取最近 300 行后全量替换。
- 日志支持暂停滚动、清空显示、搜索、复制、下载；关闭弹窗立即停止后台任务。
- 非 systemd 系统展示明确空状态，不把命令不存在显示成通用错误。

#### SSH-011 进程（P1）

- 保留搜索和 CPU/内存/PID 排序，增加自动刷新开关和刷新间隔。
- 点击行打开详情抽屉：完整命令、父 PID、启动时间、工作目录（能获取时）、打开端口（P2）。
- `结束` 发送 TERM；等待 3 秒仍存在时提示是否 KILL。
- `强杀` 保留危险确认，显示 PID、用户和完整命令，避免 PID 看错。
- 默认不提供批量强杀。

#### SSH-012 Docker（P1）

- 保留列表、筛选、启停重启、删除、日志和容器终端。
- 增加容器健康状态、CPU/内存快照、重启策略和完整端口映射。
- 点击容器打开右侧详情抽屉：基本信息、环境变量名（秘密值掩码）、挂载、网络、最近日志。
- 删除只支持已停止容器；强制删除作为 P2 且需要输入容器名称确认。
- 日志与 systemd 共用统一增量日志查看器。
- 容器终端先探测 `/bin/bash`，失败回退 `/bin/sh`，并允许用户选择。
- Docker 未安装或当前用户无权限时给出有针对性的诊断提示。

### 6.10 SSH 隧道

#### SSH-013 隧道管理（P1，旗舰新增）

这是比继续扩数据库更有价值的新能力。

页面：连接内新增“隧道”页签。

| 列 | 内容 |
|---|---|
| 名称 | 用户自定义名称 |
| 类型 | 本地转发 / 远程转发 / SOCKS5 |
| 监听 | 本地或远端监听地址和端口 |
| 目标 | 目标 host:port；SOCKS 无固定目标 |
| 状态 | 已停止、启动中、运行中、异常 |
| 流量 | 当前连接数、上传、下载 |
| 操作 | 启动/停止、编辑、复制地址、删除 |

顶部按钮：`+ 新建隧道`、`全部启动`、`全部停止`、`仅看运行中`。

新建表单：

- 名称。
- 类型：Local `-L`、Remote `-R`、Dynamic `-D`。
- 监听地址，默认本地 `127.0.0.1`，不默认暴露 `0.0.0.0`。
- 监听端口，保存前检测端口占用。
- 目标主机和端口。
- 建立 SSH 连接后自动启动开关，默认关闭。
- 断线恢复后自动重建开关，默认开启。

安全要求：

- 监听 `0.0.0.0` 或 `::` 时显示橙色警告和额外确认。
- 远程转发明确说明是否依赖服务端 `GatewayPorts`。
- 隧道失败展示监听端冲突、远端拒绝、SSH 断开等具体原因。

建议命令和事件：

- `ssh_tunnel_list(connectionId)`。
- `ssh_tunnel_start({ connectionId, config })`。
- `ssh_tunnel_stop(tunnelId)`。
- `ssh_tunnel_delete(tunnelId)`。
- `ssh://tunnel-status`、`ssh://tunnel-traffic`。

### 6.11 OpenSSH 配置导入

#### SSH-014 导入与导出（P1）

- 支持选择 `~/.ssh/config` 或用户指定文件。
- 预览 Host、HostName、Port、User、IdentityFile、ProxyJump。
- `Host *` 只作为默认值合并，不创建服务器条目。
- 通配符 Host 默认不导入，显示原因。
- IdentityFile 只在用户确认后读取并保存到 Vault；不把路径内容悄悄复制。
- 已存在的 host/port/user 组合提示覆盖、跳过或另存。
- 导出时只导出非秘密 profile；私钥不写入普通 JSON。
- 支持复制标准 `ssh user@host -p port` 命令。
