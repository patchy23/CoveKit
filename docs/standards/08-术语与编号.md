# 08 · 术语与编号

任务编号只用于本地检索，不作为仓库开发前置；历史编号解释留在本地过程材料。产品需求和 ADR 的稳定编号继续使用。

## 架构专有名词

| 术语 | 含义 |
| --- | --- |
| **owner** | 内置功能模块的边界单位，以业务能力划分；前后端目录不要求一一对应。数据文件经 paths 解析到当前空间 data 目录 |
| **DataContext** | Rust 侧不可变上下文 `{ space_id, location, epoch }`，存储位置与数据空间的唯一事实源 |
| **spaceId** | 数据空间标识（独立数据集）；未启用多空间时为默认空间 |
| **epoch** | 本次启动的上下文标识，用于判定进程内状态的新旧 |
| **location** | 固定的设备根、空间根及 data/vault/logs/cache 实际路径；不再有旧布局枚举 |
| **maintenance_guard** | `framework/context.rs` 的互斥守卫，根迁移 / 导入提交 / 空间激活 / 更新安装共用 |
| **PluginDb** | 模块数据库统一骨架：连接生命周期 + 锁 + `PRAGMA user_version` 顺序迁移 |
| **secure_store** | 框架级安全原语（加解密、主密钥来源、原子写与备份恢复、文件权限） |
| **`patchybox_module!`** | 模块门面声明的宏：owner + featureId + `命令路径 => 中文说明`，同时生成入库元数据与 handler |
| **`patchybox_routes!`** | `plugins/mod.rs` 的路由装配宏：一行/模块生成路由、装配顺序与 `validate_routing()` 启动校验 |
| **`Ui*`** | `@/core/ui` 的公共基础控件统一前缀（`UiInput` / `UiSelect` / `UiCombobox` / `UiListRow` / `UiTabsOverflow` …） |
| **`UiCodeEditor`** | 统一的代码编辑器组件（CodeMirror 6 基座），禁止自研 textarea 编辑器 |

## 检查器与门禁

| 入口 | 作用 |
| --- | --- |
| `python scripts/check_rust_rules.py` | 调用 Cargo 的 Rust AST 规范检查，含 SAFETY 逐处校验；执行边界见20 |
| `python scripts/check_docs.py` | 调用 Cargo 的 Rust 注释覆盖扫描；Markdown 链接由 check_markdown.py 检查 |
| `framework/manifest_contract_tests.rs` | IPC 清单契约：源码扫描 + 已发布命令表，拦截手写绕过 |
| `pnpm lint` / `pnpm test` / `pnpm build` | 前端门禁 |
| `cargo fmt` / `cargo clippy -- -D warnings` | CI Rust 格式和 lint 门禁；具体命令只见20 |

历史批次编号的详细定义留在对应方案，不为解释旧编号新增开发任务。
