# 07b · 网络与接口调试

本文规定接口调试与 Windows 端口查询的行为。独立网络诊断工具不在当前范围，跨工具约束见[产品范围](07-产品需求.md#当前有效范围裁决)。保留现有章节编号以兼容稳定文档链接。

## 8. 接口调试

### 8.1 当前范围

覆盖日常 HTTP、SSE、原始 WebSocket 调用与个人接口管理。工具名保持“接口调试”，稳定 ID 保持 `http-ws`，历史存储仍为 `api.db`。本节定义当前轻量接口工具的支持范围。

不纳入团队同步、Mock、脚本断言、Runner、压测、自动重连、持久化响应历史和多级变量继承。环境变量、cURL、文件上传与复杂响应预览留待独立需求；SSE/WebSocket 不扩展为 SSH、TCP、UDP 或 Socket.IO。

### 8.2 接口库与多页签

- 采用 SSH 页面相同的朴素分栏、180px 侧栏、搜索栏内新建入口和紧凑行；无大卡片、全局工具栏或状态栏。
- 左侧按路径分组管理，空白处右键添加根分组，分组右键创建子分组或 HTTP、SSE、WebSocket 接口；空分组独立保存在接口库。路径以 `/` 分隔层级，旧接口的分组路径保留，没有分组的接口显示在未分组。
- 搜索名称、地址、方法或协议；支持保存、另存、重命名、移动分组与确认删除接口。重命名仅更新名称和分组，同一接口的保存、重命名、删除互斥，避免旧快照覆盖请求。
- 逻辑请求导入导出包含所属分组路径和接口排序；旧包缺少排序时，新记录追加末尾，已存在记录保留顺序。完整恢复左侧树需同时选择“接口分组与布局”，其中包含空分组和分组排序；布局作为整体处理冲突，不支持保留两份。使用导入布局替换分组目录时仍保留现有接口引用的路径。
- 方法标记使用既有颜色：GET 绿、POST 橙、PUT 蓝、PATCH 紫、DELETE 红，侧栏和请求方法选择器保持一致。选中行只使用整行背景，不叠加行内按钮的灰色悬停背景。
- 子分组使用按钮外层缩进与文件夹图标区分层级，避免公共控件内边距覆盖层级。接口可拖到其他分组或未分组；投放目标高亮，Esc 取消。移动仅更新分组归属，保留打开接口的未保存修改与连接。
- 接口与分组菜单提供独立“移动到…”入口，以公共树形下拉选择目标，支持搜索和完整路径回显；分组排除自身及后代，提供根目录，接口提供未分组。保存接口也使用树形分组选择，重命名仅修改名称。拖拽继续保留。
- 分组可连同子分组及接口拖到其他分组，拖动时提供“移至根目录”入口；禁止移入自身或后代，同级重名拒绝合并。目录与接口归属在同一事务中更新，保留原上级空分组及打开的草稿和连接。
- 右侧顶部为接口页签，协议绑定接口，仅新建时选择。重复打开同一接口只激活，不覆盖编辑内容。
- 每页签独立保留请求草稿、响应、认证临时值、消息输入和连接；切换不重新发送或断开。页签多时使用公共溢出入口。
- 新建未保存及已保存后再次修改的页签，名称前均显示 `*`，保存成功后清除；关闭可保存、丢弃或取消。活动长连接关闭时提示断开。关闭单页签只清理所属连接，关闭工具清理全部。迟到响应不能污染新页签，迟到连接须回收。
- 未保存标记只显示在内部接口页签，顶层工具页签不显示未保存圆圈；关闭工具时的未保存提醒保留。
- `Ctrl/Cmd+Enter` 发送或连接，`Ctrl/Cmd+S` 保存；动作只作用于当前接口页签。

### 8.3 请求构建与认证

- 紧凑地址行包括方法、URL、发送或连接、保存与另存。配置子页为参数、认证、请求头、请求体和设置，可整体收起。
- 参数、请求头和表单使用可启停键值行；保留重复项，查询参数正确处理已有 query 和 fragment。
- HTTP 支持 GET、POST、PUT、PATCH、DELETE、HEAD、OPTIONS；请求体支持 None、JSON、Text、Form URL Encoded。JSON 发送前检查语法；指定请求体不因方法静默丢弃。
- 认证支持 None、Basic、Bearer。Basic 使用 password 凭证，Bearer 使用 api-token 凭证，后端经公共凭证库解析；也可填写仅保留在当前页签的临时值。
- 保存接口只保存认证模式与凭证引用；接口库自报凭证引用。逻辑导出不携带本机凭证引用，导入后重新选择；手工填写的请求头与请求体按用户原文保存。
- 默认超时 15 秒，可选 5、15、30、60 秒。HTTP 限制整个请求，SSE/WebSocket 只限制握手。HTTP 跟随重定向、校验 TLS 证书。

### 8.4 HTTP 响应

固定显示状态码、总耗时、响应字节数与完成时间；内容提供格式化、原文、响应头和复制，代码查看统一使用公共编辑器。400/500 等响应保留内容；网络错误、读取中断和超过 20 MiB 明确报错，不冒充空响应成功。当前以文本查看为主。

发送中禁止重复发送。HTTP 暂无取消任务契约，不提供假取消按钮；关闭页签后丢弃迟到结果，后端请求由超时约束结束。

### 8.5 SSE

- 共用 HTTP 参数、请求头、认证与请求体；支持 GET 和 POST JSON 流式接口，默认 Accept 为 text/event-stream。Last-Event-ID 可通过请求头显式设置。
- 开始订阅、停止订阅，展示状态、握手响应头与事件列表；支持内容搜索、展开详情、复制、清空视图和跟随最新。
- 按 UTF-8、跨块行、CR/LF/CRLF、空行事件边界增量解析；支持多行 data、注释心跳、event、id、retry；不要求 JSON，也不把 `[DONE]` 当作通用结束信号。
- 连接失败、非成功状态、错误媒体类型与事件超限均可感知。停止立即取消后端任务；服务端结束后保留已收事件，不自动重连。

### 8.6 WebSocket 与缓存边界

- 支持 ws/wss、query、自定义握手 Header 和认证，连接状态由所属页签持有。
- 文本与 JSON 按原文发送；后台实际写入成功才记录发送。失败保留输入，支持从日志填回发送框。
- 收发日志支持方向筛选、搜索、展开、复制与清空；二进制消息展示长度和有限十六进制摘要。
- WS 轮询无重入，非活动页签降低频率，关闭后释放轮询与网络任务。
- 每页签最多保留最近 500 条消息；旧条目淘汰数量可见。SSE 单行/事件、WS 单条消息有大小限制，避免无限积累。

## 15. 本机端口占用查询

### 15.1 SYS-001 端口占用

Windows 系统工具，入口与文件占用查询分开；共用框架的进程详情、启动身份核对和关闭能力。macOS 显式显示不支持。

页面：

- 按本地端口号、进程名或 PID 筛选；端口与 PID 精确匹配，进程名忽略大小写匹配子串。
- 同时读取 TCP/UDP、IPv4/IPv6，支持协议筛选；默认显示 TCP LISTEN 与 UDP 绑定，切换全部连接后展示其他 TCP 状态及远端地址。
- 表格保留同端口的多条记录，展示协议、地址族、本地地址与端口、状态、进程名、PID 和程序路径；长文本单行省略，可悬停查看。每页最多 100 条。
- 支持复制端口与进程信息、打开程序所在目录、确认后关闭进程；关闭会结束整个进程，须提示未保存内容可能丢失。
- 关闭前在后端重新核对完整端点与 PID、启动时间；拒绝关闭自身、系统保留及关键进程，权限不足直接提示，不自动提权。成功后刷新快照。
- 手动刷新与可选的每 3 秒自动刷新；非活动页签、窗口隐藏、设置页覆盖或关闭确认期间暂停自动刷新，卸载释放定时器。查询失败停止自动刷新，保留旧快照并禁止关闭，成功重试后恢复操作。
- 单个协议或地址族失败单独提示，不伪装成无占用；进程详情不可读时保留端点与 PID，禁用无法验证身份的关闭操作。空列表不保证端口可以绑定。

后端使用 Windows IP Helper 的 OWNER_PID 表，不解析命令行文本。每个快照按 PID 复用详情查询，不保留跨请求进程缓存。缓冲区、重试和结果数量有上限。当前不包含 SSH 跳转、网络诊断联动或批量关闭。
