## 7. 网络诊断（建议新增）

### 7.1 定位

网络诊断是 SSH、DNS 和 HTTP 之间缺失的一环。它是确定性程序能力，不需要 Agent，且能让现有三个工具形成一条完整排障链。

### 7.2 页面布局

#### NET-001 一键链路诊断（P1）

```text
┌──────────────────────────────────────────────────────────────────┐
│ 目标 [https://example.com:8443/path________] [开始诊断] [停止] │
│ 预设：URL / 主机+端口 / SSH 服务器                 [导出报告] │
├─────────────────┬────────────────────────────────────────────────┤
│ 最近目标        │ ① DNS       12 ms   1.2.3.4                   │
│ example.com     │ ② TCP       28 ms   已连接                    │
│ api.example.com │ ③ TLS       41 ms   有效至 2026-12-01         │
│ 192.168.1.10:22 │ ④ HTTP      89 ms   200 OK                    │
│                 │ ⑤ 路由追踪   可选                              │
├─────────────────┴────────────────────────────────────────────────┤
│ 详情：阶段日志 / 解析记录 / 证书链 / 响应头 / 路由节点          │
└──────────────────────────────────────────────────────────────────┘
```

目标输入规则：

- URL：自动提取协议、host、port 和 path。
- `host:port`：执行 DNS（如需要）和 TCP。
- 纯 host/IP：默认执行 DNS/Ping；可选择端口。
- SSH 联动传入 profile 时展示 profile 名称，但不读取 SSH 凭证。

开始后按阶段显示：等待、进行中、成功、警告、失败、跳过。某阶段失败不一定阻止后续可独立执行的阶段。

### 7.3 诊断能力

#### NET-002 DNS 阶段（P1）

- 系统 DNS 解析 A/AAAA。
- 展示 CNAME 链、最终地址和耗时。
- “在 DNS 工具中详细比较”按钮投递 Tool Intent。

#### NET-003 连通性阶段（P1）

- ICMP Ping：次数 4，展示丢包、最小/平均/最大延迟；权限不允许时说明并继续 TCP。
- TCP connect：目标端口、超时、建立耗时和错误码。
- 可并行检查一组常用端口，但上限 20 个，不做网段扫描器。
- “本机端口被占用”时联动本机端口查看器。

#### NET-004 TLS 证书（P1）

- SNI、TLS 版本、cipher suite。
- 证书主题、SAN、签发者、序列号、SHA256 指纹。
- 生效/过期时间和剩余天数。
- 证书链是否完整、主机名是否匹配、系统是否信任。
- 剩余小于 30 天显示警告，已过期显示失败。
- 支持复制 PEM 和导出证书信息，不保存私钥。

#### NET-005 HTTP 阶段（P1）

- 默认 HEAD；服务不支持时提示可改 GET，不自动下载大响应体。
- 展示状态、重定向链、最终 URL、响应头、首字节和总耗时。
- “在 HTTP 调试中打开”按钮预填请求，不自动发送。

#### NET-006 路由追踪（P2）

- Windows 使用系统兼容实现或后端原生探测，macOS/Linux 使用对应能力。
- 逐跳显示序号、IP、反向域名、三次延迟和超时。
- 支持取消；最长 30 跳；不会阻塞整个 Tauri 命令线程。

### 7.4 后端交互

长诊断使用任务 + 事件，不使用一个超长阻塞 invoke：

- `net_diagnosis_start({ target, options }) -> { taskId }`。
- `net_diagnosis_cancel(taskId)`。
- `net_tcp_probe({ host, ports, timeoutMs })`。
- `net_tls_inspect({ host, port, serverName })`。
- `net_trace_start({ host, maxHops })`。
- `net://diagnosis-stage` 推送阶段结果。
- `net://trace-hop` 推送每一跳。

诊断报告导出为 Markdown 或 JSON，默认隐藏本机用户名、内网接口和代理认证信息。

## 8. 接口调试

### 8.1 当前范围

覆盖日常 HTTP、SSE、原始 WebSocket 调用与个人接口管理。工具名保持“接口调试”，稳定 ID 保持 `http-ws`，历史存储仍为 `api.db`。本节按当前轻量化裁决维护，替代此前完整 API 工作台的规划。

不纳入团队同步、Mock、脚本断言、Runner、压测、自动重连、持久化响应历史和多级变量继承。环境变量、cURL、文件上传与复杂响应预览留待独立需求；SSE/WebSocket 不扩展为 SSH、TCP、UDP 或 Socket.IO。

### 8.2 接口库与多页签

- 采用 SSH 页面相同的朴素分栏、180px 侧栏、搜索栏内新建入口和紧凑行；无大卡片、全局工具栏或状态栏。
- 左侧按路径分组管理，空白处右键添加根分组，分组右键创建子分组或 HTTP、SSE、WebSocket 接口；空分组独立保存在接口库。路径以 `/` 分隔层级，旧接口的分组路径保留，没有分组的接口显示在未分组。
- 搜索名称、地址、方法或协议；支持保存、另存、重命名、移动分组与确认删除接口。逻辑请求导入恢复所属分组路径；空分组随完整数据目录备份保留。
- 方法标记使用既有颜色：GET 绿、POST 橙、PUT 蓝、PATCH 紫、DELETE 红，侧栏和请求方法选择器保持一致。选中行只使用整行背景，不叠加行内按钮的灰色悬停背景。
- 右侧顶部为接口页签，协议绑定接口，仅新建时选择。重复打开同一接口只激活，不覆盖编辑内容。
- 每页签独立保留请求草稿、响应、认证临时值、消息输入和连接；切换不重新发送或断开。页签多时使用公共溢出入口。
- 新建未保存及已保存后再次修改的页签，名称前均显示 `*`，保存成功后清除；关闭可保存、丢弃或取消。活动长连接关闭时提示断开。关闭单页签只清理所属连接，关闭工具清理全部。迟到响应不能污染新页签，迟到连接须回收。
- `Ctrl/Cmd+Enter` 发送或连接，`Ctrl/Cmd+S` 保存；动作只作用于当前接口页签。

### 8.3 请求构建与认证

- 紧凑地址行包括方法、URL、发送或连接、保存与另存。配置子页为参数、认证、请求头、请求体和设置，可整体收起。
- 参数、请求头和表单使用可启停键值行；保留重复项，查询参数正确处理已有 query 和 fragment。
- HTTP 支持 GET、POST、PUT、PATCH、DELETE、HEAD、OPTIONS；请求体支持 None、JSON、Text、Form URL Encoded。JSON 发送前检查语法；指定请求体不因方法静默丢弃。
- 认证支持 None、Basic、Bearer。Basic 使用 password 凭证，Bearer 使用 api-token 凭证，后端经公共凭证库解析；也可填写仅保留在当前页签的临时值。
- 保存接口只保存认证模式与凭证引用；接口库自报凭证引用。逻辑导出不携带本机凭证引用，导入后重新选择；手工填写的请求头与请求体按用户原文保存。
- 默认超时 15 秒，可选 5、15、30、60 秒。HTTP 限制整个请求，SSE/WebSocket 只限制握手。HTTP 跟随重定向、校验 TLS 证书。

### 8.4 HTTP 响应

固定显示状态码、总耗时、响应字节数与完成时间；内容提供格式化、原文、响应头和复制，代码查看统一使用公共编辑器。400/500 等响应保留内容；网络错误、读取中断和超过 20 MiB 明确报错，不冒充空响应成功。当前以文本查看为主。

发送中禁止重复发送。HTTP 暂无取消任务契约，不提供假取消按钮；关闭页签后丢弃迟到结果，后端请求由超时约束结束。

### 8.5 SSE

- 共用 HTTP 参数、请求头、认证与请求体；支持 GET 和 POST JSON 流式接口，默认 Accept 为 text/event-stream。Last-Event-ID 可通过请求头显式设置。
- 开始订阅、停止订阅，展示状态、握手响应头与事件列表；支持内容搜索、展开详情、复制、清空视图和跟随最新。
- 按 UTF-8、跨块行、CR/LF/CRLF、空行事件边界增量解析；支持多行 data、注释心跳、event、id、retry；不要求 JSON，也不把 `[DONE]` 当作通用结束信号。
- 连接失败、非成功状态、错误媒体类型与事件超限均可感知。停止立即取消后端任务；服务端结束后保留已收事件，不自动重连。

### 8.6 WebSocket 与缓存边界

- 支持 ws/wss、query、自定义握手 Header 和认证，连接状态由所属页签持有。
- 文本与 JSON 按原文发送；后台实际写入成功才记录发送。失败保留输入，支持从日志填回发送框。
- 收发日志支持方向筛选、搜索、展开、复制与清空；二进制消息展示长度和有限十六进制摘要。
- WS 轮询无重入，非活动页签降低频率，关闭后释放轮询与网络任务。
- 每页签最多保留最近 500 条消息；旧条目淘汰数量可见。SSE 单行/事件、WS 单条消息有大小限制，避免无限积累。

## 15. 新增本机端口查看器（可选 P2）

### 15.1 SYS-001 端口占用

这是一个小而高频、可与 SSH 隧道和网络诊断联动的本机工具。

页面：

- 顶部搜索端口、进程名、PID。
- 协议筛选 TCP/UDP，状态筛选 LISTEN/ESTABLISHED。
- 表格：协议、本地地址、端口、远端地址、状态、PID、进程、启动路径。
- 操作：复制地址、打开文件位置、结束进程、网络诊断。
- 结束进程必须确认；系统进程或权限不足时明确提示，不自动提权。
- SSH 隧道端口冲突弹窗可跳转并高亮对应端口。

后端按平台实现适配器，输出统一模型；不通过解析本地化命令行文本作为唯一可靠来源。
