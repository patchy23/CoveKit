## 11. 格式与数据工具

### 11.1 边界

这里适合做确定、可复现、可离线的转换。不会接入 LLM 猜测文件含义，也不做复杂批量文档生产。

### 11.2 页面结构

#### DATA-001 数据工作台（P1/P2）

将当前“格式转换”扩展为以下子页签，并继续用 `v-show` 保留各页输入：

1. JSON。
2. XML。
3. YAML/TOML（P2）。
4. 时间戳。
5. 编码（Base64、URL、Hex）。
6. JWT。
7. 哈希/校验和。
8. 文本对比（P2）。
9. 正则测试（P2）。

顶部通用按钮：从剪贴板粘贴、打开文件、交换左右、复制结果、保存结果、清空。打开文件默认限制 20 MiB，超限提示改用专用工具。

### 11.3 JSON

#### DATA-002 JSON（P1）

- 左输入、右输出，保留行号。
- 按钮：格式化、压缩、校验、转义、反转义、复制、保存。
- 缩进固定 2 空格（2026-09-14 工具级设置缩减：不再提供 2/4/Tab 选择项）。
- 错误显示行、列、附近片段，并能点击定位。
- 可选排序对象 key；默认关闭，避免无意改变字段顺序。
- JSONPath 查询作为 P2：底部输入表达式，高亮并输出匹配结果。
- 不做“智能修复后直接覆盖”；可提供修复建议，但必须展示差异并由用户确认。

### 11.4 XML / YAML / TOML

#### DATA-003 结构化格式（P2）

- XML：格式化、压缩、校验、XML ↔ JSON。
- YAML：格式化、校验、YAML ↔ JSON。
- TOML：格式化、校验、TOML ↔ JSON。
- 转换前说明可能丢失注释、锚点、属性顺序或类型信息。
- 默认不在错误输入上强行转换。

### 11.5 编码与时间

#### DATA-004 编码（P1）

- Base64 文本编码/解码，支持标准和 URL-safe。
- URL encode/decode，可选择整体或 Query Component。
- UTF-8 文本 ↔ Hex。
- 自动识别只用于推荐操作，不自动修改输入。
- 解码失败显示明确原因和非法位置。

#### DATA-005 时间戳（P1）

- 秒/毫秒/微秒时间戳和日期时间互转。
- 当前时间实时刷新，可暂停和复制。
- 时区选择：本地、UTC、固定 UTC offset；IANA 时区 P2。
- 支持 ISO 8601、RFC 3339 和自定义常用格式。
- 展示相对时间，如“3 小时前”，但复制仍使用精确值。

### 11.6 JWT 与哈希

#### DATA-006 JWT 查看器（P1）

- 三段输入自动拆分 Header/Payload/Signature。
- Header 和 Payload 只做 Base64URL 解码与 JSON 展示。
- 展示 `exp/nbf/iat` 的本地时间和是否过期。
- 明确警告：“解码不等于验签”。
- P2 支持使用用户临时输入的 HMAC secret 或公钥验签；秘密不默认保存。
- 不提供伪造生产 Token 的一键功能。

#### DATA-007 哈希/校验和（P1）

- 文本或文件输入。
- 算法：MD5（兼容用途并标记不安全）、SHA-1（标记不安全）、SHA-256、SHA-512、BLAKE3。
- 文件使用 Rust 流式读取并通过任务事件显示进度，避免大文件进入前端内存。
- 支持输入期望 hash 后比较，成功/失败明显展示。
- 按钮：计算、停止、复制、保存 checksum 文件。

### 11.7 文本对比与正则

#### DATA-008 文本对比（P2）

- 左右双栏输入，下方或中央展示行级 diff。
- 忽略空白、忽略大小写、只显示差异开关。
- 支持复制 unified diff、保存 `.patch`。
- 仅处理文本，不承担目录同步或 Git 客户端职责。

#### DATA-009 正则测试（P2）

- 正则、flags、测试文本、替换模板四区。
- 实时高亮匹配，展示捕获组和匹配数量。
- 防止灾难性回溯卡死：放入 Worker 或后端带超时执行。
- 明确当前使用的正则引擎及与 JavaScript/Rust 的差异。

## 12. 文字转语音

### 12.1 定位

TTS 是独立的低频实用工具。保持轻量，不发展成音频编辑器。

### 12.2 TTS-001 隐私与服务状态（P0）

- 页面顶部明确写明文本会发送到 Microsoft Edge TTS 服务进行合成。
- 首次使用弹一次说明，用户确认后再发送；选择只保存在本机。
- 提供服务不可用、超时、限流、网络错误的区别提示。
- 隐私说明中写明 CoveKit 自身不上传到作者服务器。

### 12.3 TTS-002 页面完善（P2）

左侧：

- 文本输入与字数。
- 音色按语言/地区分组，可搜索。
- 每个音色“试听”按钮，试听固定短句并缓存。
- 语速、音调和音量；支持恢复默认。
- 参数预设：旁白、轻快、慢速等，用户可保存自定义预设。

右侧：

- 当前结果播放器。
- 文件名、格式、大小、时长。
- 下载、打开所在目录、重新合成。
- 最近生成列表，默认只记录本机文件路径和参数，不记录原文；可在设置关闭。

### 12.4 TTS-003 长文本队列（P2）

- 超过服务单次上限时按段落和标点切块，不从单词/数字中间截断。
- 列出分段预览，用户可调整。
- 每段作为子任务合成，最终合并 MP3；合并失败保留已生成分段。
- 支持取消和重试失败段。
- 设置最大总字数，防止误粘贴超大文本。
- 临时音频默认 7 天自动清理；设置页可立即清理并显示占用空间。

建议后端：

- `tts_synthesize_start({ textSegments, voice, rate, pitch, volume, outputPath })`。
- `tts_task_cancel(taskId)`。
- `tts_cache_stats/clear`。
- 进度统一进入任务中心。

## 13. 数据库工作台：开发与测试范围

### 13.1 决策

数据库工具按日常开发、测试需求完善执行正确性、交互和紧凑 UI。优先 MySQL、PostgreSQL、SQLite、Redis；Oracle 保留 agent 适配，驱动与实机验收单列。此范围替代旧的仅收尾冻结及表数据只读限制，不延伸为数据库管理平台。

### 13.2 功能范围

- 连接保存、测试、连接和断开；公共 Vault 引用、旧密码可恢复迁移、生产默认只读。
- 对象树、完整执行目标、表结构和稳定分页；精确统计按需触发。
- SQL 选区/当前语句/脚本执行，独立页签会话、事务、真实取消、多结果和类型保真。
- 文件打开/另存、自动草稿恢复、查询历史、收藏、EXPLAIN 与可审阅的测试数据 SQL 模板。
- 服务端组合条件、NULL、IN、范围、排序和 SQL 预览；参数绑定不能拼接值。
- 可靠主键单表新增/更新/删除，完整原值并发校验、显式提交和事务回滚；不编辑 JOIN/聚合结果。
- 有界 CSV 预览、列映射、指纹核验和单事务导入；已加载结果导出与完整只读查询流式导出分别标识。
- Redis 游标扫描、加载更多、ACL/TLS 与有界类型预览。
- 既有建库、DDL、索引和表管理入口保持目标一致、只读保护和危险操作确认。

### 13.3 可靠性要求

- 支持矩阵由实际驱动契约决定；达梦未实现前不在新建列表出现，agent 类型选择时立即显示依赖状态。
- 作用域、请求代次和确认票据绑定真实执行目标，旧响应不覆盖新状态。
- 只读由后端实施，未知语法保守处理；危险 SQL 显示目标与摘要。
- 取消请求、执行终止、正常完成、结果未知明确区分；不能用停止前端等待冒充回滚。
- NULL、空串、文本 NULL、二进制、大整数和高精度小数在复制/导出时可区分。
- 结果按行、字节和时间限制；不能因达到展示上限而遗留未完成协议。
- 关闭工具保护活动事务和运行任务，草稿只恢复文档，不连接或执行 SQL。
- 无实机条件不宣布对应驱动或平台通过；协议夹具、单测和真实 UI 验收分别记录。

### 13.4 UI 原则

内容优先，基础控件优先 xs、工具栏 compact，SQL 新建入口固定可见；右侧摘要按需折叠。编辑页保留独立撤销、光标与滚动。新建连接复用公共凭证组件，高级选项收起。后台不轮询整棵对象树，大结果不深度响应式代理。状态、错误、限制及下一步操作必须可见。

### 13.5 明确不新增

不新增数据库类型、ER 图、数据建模、结构同步、通用数据库迁移、DBA 监控、团队连接共享或批量数据修复平台。不内置数据库专属 SSH 隧道；需要时使用 SSH 模块公开能力创建本地转发端口。各驱动详细边界见[数据库设计](../plugins/database/设计.md)。
