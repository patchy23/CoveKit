# 07d · 数据与媒体工具

跨工具边界见[产品范围](07-产品需求.md#当前有效范围裁决)。数据库章节保留稳定编号，具体实现契约由对应模块文档维护。

## 格式转换

JSON、XML、时间戳、Base64 组成同一工具的四个子页签。切换保留各面板输入，输入经 300ms 防抖自动转换，模式和方向切换立即重算；空输入清空结果，不按错误处理。

JSON 与 XML 提供格式化、压缩和校验反馈；JSON 格式化缩进固定 2 空格。时间戳提供时间转换；Base64 按 UTF-8 文本编解码，遇到不能安全显示的二进制内容明确报错，不产生乱码结果。工具不上传输入正文。

当前不包含独立 YAML/CSV 转换、JWT、哈希、文本对比或正则测试工具；这些旧设想不构成现行开发要求。

## 文字转语音

使用 Microsoft Edge 在线语音服务，将输入文本发送给第三方进行合成，结果缓存为 MP3 并可播放、下载。支持内置中文音色、语速和音调调节，单次文本限制以实际校验为准。

输入为空、文本超限、网络失败、缓存写入失败应分别可感知；失败不得返回可播放结果。下载使用用户选择的目标，不向日志记录正文。长文本分段队列、音频编辑、预设管理和历史面板不在当前范围。

## 13. 数据库工作台：开发与测试范围


### 13.1 决策

数据库工具按日常开发、测试需求完善执行正确性、交互和紧凑 UI。优先 MySQL、PostgreSQL、SQLite、Redis；Oracle 保留 agent 适配，驱动与实机验收单列。允许单表数据编辑，不延伸为数据库管理平台。

### 13.2 功能范围

- 连接保存、测试、连接和断开；公共 Vault 引用、旧密码可恢复迁移、生产默认只读。
- 对象树、完整执行目标、表结构和稳定分页；精确统计按需触发。
- SQL 选区/当前语句/脚本执行，独立页签会话、事务、真实取消、多结果和类型保真。
- 文件打开/另存、自动草稿恢复、查询历史、收藏、EXPLAIN 与可审阅的测试数据 SQL 模板。
- 服务端组合条件、NULL、IN、范围、排序和 SQL 预览；参数绑定不能拼接值。
- 可靠主键单表新增/更新/删除，完整原值并发校验、显式提交和事务回滚；不编辑 JOIN/聚合结果。
- 有界 CSV 预览、列映射、指纹核验和单事务导入；已加载结果导出与完整只读查询流式导出分别标识。
- Redis 游标扫描、加载更多、ACL/TLS 与有界类型预览。
- 既有建库、DDL、索引和表管理入口保持目标一致、只读保护和危险操作确认。

### 13.3 可靠性要求

- 支持矩阵由实际驱动契约决定；达梦未实现前不在新建列表出现，agent 类型选择时立即显示依赖状态。
- 作用域、请求代次和确认票据绑定真实执行目标，旧响应不覆盖新状态。
- 只读由后端实施，未知语法保守处理；危险 SQL 显示目标与摘要。
- 取消请求、执行终止、正常完成、结果未知明确区分；不能用停止前端等待冒充回滚。
- NULL、空串、文本 NULL、二进制、大整数和高精度小数在复制/导出时可区分。
- 结果按行、字节和时间限制；不能因达到展示上限而遗留未完成协议。
- 关闭工具保护活动事务和运行任务，草稿只恢复文档，不连接或执行 SQL。
- 无实机条件不宣布对应驱动或平台通过；协议夹具、单测和真实 UI 验收分别记录。

### 13.4 UI 原则

内容优先，基础控件优先 xs、工具栏 compact，SQL 新建入口固定可见；右侧摘要按需折叠。编辑页保留独立撤销、光标与滚动。新建连接复用公共凭证组件，高级选项收起。后台不轮询整棵对象树，大结果不深度响应式代理。状态、错误、限制及下一步操作必须可见。

### 13.5 明确不新增

不新增数据库类型、ER 图、数据建模、结构同步、通用数据库迁移、DBA 监控、团队连接共享或批量数据修复平台。不内置数据库专属 SSH 隧道；需要时使用 SSH 模块公开能力创建本地转发端口。各驱动详细边界见[数据库设计](../plugins/database/设计.md)。
