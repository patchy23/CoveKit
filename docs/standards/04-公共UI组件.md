# 公共前端组件库

公共组件统一位于 `src/core/ui/`，业务插件只能从 `@/core/ui` 导入通用控件（基础控件）；依赖凭证库、平台句柄或应用通知的**复合能力不进 `core/ui`**，见 §1 末尾的分层表。组件库采用 shadcn-vue 的源码所有权与组合方式，Select、Dialog、Tabs、Checkbox、Radio、Switch 等交互由 Reka UI 原语提供；`DESIGN.md` token 仍是视觉单一事实源，不使用 shadcn-vue 默认皮肤，也不在插件中复制按钮、表单、页签、弹窗和状态色组合。

根目录 `components.json` 记录 shadcn-vue CLI 的目录和 Tailwind 4 配置。CLI 只用于按需取得组件源码；生成后必须转换成现有 `Ui*` API，并按组件实验室基线验收，业务插件不得直接导入 `reka-ui`。

## 1. 组件清单

| 组件 | 用途 | 关键约定 |
| --- | --- | --- |
| `UiButton` | 按钮与链接按钮 | `primary / secondary / ghost / danger`；四档尺寸、loading、disabled、block，禁用链接阻止导航 |
| `UiInput` | 单行输入 | 原生属性透传；支持 `v-model.trim`、`v-model.number`、invalid |
| `UiTextarea` | 多行输入 | 支持 resize 与 invalid |
| `UiSelect` | 下拉选择 | 自动上下翻转；支持禁用选项和业务颜色映射 |
| `UiCombobox` | 可搜索选择 | 输入过滤、键盘选择；选项多或需要搜索时使用 |
| `UiField` | 字段布局 | 统一标签、必填、说明、错误信息 |
| `UiTabs` | 页签 | `pill` 用于视图切换，`line` 用于工作区功能切换 |
| `UiPanel` | 内容面板与折叠区 | 标题、说明、操作区、内边距；collapsible 保留内容状态，支持 Enter/空格 |
| `UiBadge` | 状态徽标 | 仅使用已有语义 tone |
| `UiAlert` | 行内反馈 | info、success、warning、danger |
| `UiToolbar` | 工具栏 | 纯操作行（默认）或页面头部栏（`bordered` + `title`），右侧操作走 `#trailing` |
| `UiEmptyState` | 空状态 | 标题、说明、图标与可选操作 |
| `UiModal` | 弹窗壳 | 统一 Esc、遮罩关闭、宽度、标题和 footer；`size="full"` 为工作台型弹窗（代码编辑器/终端），高度撑满、header/footer 固定 |
| `UiCheckbox / UiRadioGroup / UiSwitch` | 选择控件 | 复选、互斥选择与功能开关；RadioGroup 的 chips 变体用于互斥筛选 |
| `UiSearchInput / UiIconButton` | 高频操作 | 搜索清空与纯图标动作 |
| `UiTable / UiTableCell / UiPagination` | 数据页面 | 表格密度、内容字体语义与受控分页 |
| `UiProgress / UiSkeleton / UiSpinner` | 加载反馈 | 确定/不确定进度、占位骨架和局部加载 |
| `UiAvatar / UiKbd / UiDivider` | 信息元素 | 头像、快捷键与内容分隔 |
| `UiTooltip` | 纯文字悬停提示 | 全局单实例显示、默认向下、自动避让、鼠标穿透 |
| `UiScrollArea` | 滚动区域 | 横向、纵向、双向；原生拖动，统一主题，managed 兼容编辑器和终端 |
| `UiListRow / UiTree` | 列表与层级导航 | 行壳和树交互；普通行的动作语义由调用方提供 |
| `UiDataGrid` | 工作台数据网格 | 结果集展示与选择，沿用数据字体与表格密度约定 |
| `UiSplitPane / UiStatusBar` | 工作台布局 | 可调整分栏与底部状态区 |
| `UiTabsOverflow` | 页签溢出收纳 | 与 UiTabs + useTabsOverflow 组合承载工作台多页签，禁止业务页再实现私有溢出菜单；底层基于 UiDropdownMenu |
| `UiDropdownMenu` | 触发器式下拉菜单 | 按钮触发的动作/选项菜单（与坐标式 ContextMenu 互补），键盘与焦点由 reka 承载 |
| `UiKvEditor` | 键值对行编辑器 | HTTP Params/Headers、连接参数等「键+值」行编辑，行 id 由组件生成 |
| `UiCodeEditor / UiCodeDiff` | 代码编辑与差异 | 公共 CodeMirror 6 基座；只读高亮查看用 `UiCodeEditor readonly`，禁止另引 highlight.js 等平行高亮方案 |
| `UiRange` | 数值区间输入 | 连续数值的滑动选择 |

`ConfirmDialog`、`InputDialog`、`ContextMenu` 属于复合公共组件，与基础控件同目录，按具体路径（`@/core/ui/ContextMenu.vue`）引用，不经 `@/core/ui` 入口，避免自身 barrel 回流成环。

### 选用与扩展

- 结果筛选选 `UiRadioGroup variant="chips"`，视图/内容页切换选 `UiTabs`；需要多选时用复选框，不混用单选和页签语义。
- 高级设置折叠直接使用 `UiPanel collapsible`；普通输入、搜索选择、加载和空状态已有对应控件，先查清单和[API 备忘](11a-公共组件API备忘.md)。
- 动作列表使用 `ContextMenu`，组件负责键盘操作、实际尺寸定位及关闭焦点；业务只提供坐标、选项和动作。普通说明使用 `UiTooltip`，需要点击和复制的内容不能塞进悬停提示。
- 提前准备以实际调用场景为依据。日期选择、上传队列、抽屉等尚无稳定公共契约的能力，出现需求后再决定复用、组合或新增，避免建立没人使用的平行组件。

### 1.1 不在 `core/ui` 的相邻能力（2026-09-12 分层落定）

| 能力 | 落点 | 使用方式 |
| --- | --- | --- |
| 凭证复合组件（`CredentialPicker`、`CredentialForm`） | `src/core/vault/ui/` | `import { CredentialPicker } from '@/core/vault'`；编辑表单同理经 `@/core/vault` |
| 剪贴板 / 窗口等平台操作与环境判断 | `src/core/platform/` | `writeClipboardText()` / `runWindowAction()` 返回结果对象，不直接提示 |
| 应用级通知辅助 | `src/core/feedback/` | `useCopy()`：组合平台调用与 toast，工具侧复制统一走这里 |

边界由门禁强制：`core/ui` 不得依赖 `stores`/`vault`/`features`/`plugins` 与业务 IPC（`pnpm check:deps`，规则见 `scripts/check_frontend_deps.mjs`）；基础 Ui 组件的单测不引入 Pinia 与 Vault mock（`src/core/ui/components.test.ts`）。

## 2. 尺寸体系

基础控件统一使用 `size="xs | sm | md | lg"`：

| 尺寸 | 控件高度 | 典型场景 |
| --- | --- | --- |
| `xs` | 24px | 表格行内操作、状态筛选、超紧凑工具栏 |
| `sm` | 28px | SSH/DNS/数据库列表、侧栏、分页 |
| `md` | 36px | 普通工具页、标准表单和操作栏 |
| `lg` | 42px | 舒适表单、首次引导和重点操作 |

`UiTable` 使用独立的 `density="compact | default | comfortable"`；数据密集工具不要通过缩小整个页面字号来获得紧凑效果。

表头不换行是内置行为（`whitespace-nowrap`），宽度不足由外层横向滚动兜底；表头默认即可拖拽调宽（右缘手柄，双击复位自动宽度），个别不应调宽的列用 `:resizable="false"` 关闭，不要在业务侧自写拖拽手柄。

### 表格内容字体契约

表格中的 `th/td` 必须使用 `UiTableCell`，页面只能通过 `content` 声明内容类型，不能直接添加 `font-sans` 或 `font-mono`：

| content | 用途 | 字体规则 |
| --- | --- | --- |
| `text` | 中文名称、说明、普通文本 | `font-data` |
| `technical` | ID、主机、镜像、服务名、路径 | `font-data` |
| `numeric` | 数量、百分比、延迟、TTL | `font-data` + 等宽数字 |
| `status` | 在线、失败、运行中等状态 | `font-data` |
| `action` | 操作列 | `CoveKit Sans` |
| `code` | 表格内的命令、SQL、原始值 | `font-data` |

表头使用 `CoveKit Sans`；除操作列外，表格正文统一使用独立的 `font-data` token，其中拉丁字符/数字使用 Cascadia Code / Consolas，中文使用系统无衬线中文字体。操作列继续使用 `CoveKit Sans`。`font-data` 的字形当前与技术区一致，但语义上和终端、日志、代码编辑器使用的 `font-mono` 解耦，后续可以独立调整而不互相影响。

## 3. 使用规则

```vue
<script setup lang="ts">
import { UiButton, UiField, UiInput, UiPanel } from '@/core/ui'
</script>

<template>
  <UiPanel title="连接设置" description="配置只保存在本机。">
    <UiField label="主机" required>
      <UiInput v-model.trim="host" class="font-mono" placeholder="127.0.0.1" />
    </UiField>
    <UiButton variant="primary" :loading="saving" @click="save">保存</UiButton>
  </UiPanel>
</template>
```

- 业务页不再直接使用 `btn-*`、`field-*` 组合类；这些类是组件内部实现细节。
- 业务按钮统一用 `UiButton` 或 `UiIconButton`；底层公共组件可以使用原生元素。窗口控制与表格行内图标也优先复用，特殊语义按公共组件能力扩展。
- 字段错误通过 `UiField.error + UiInput.invalid` 表达，异步或跨字段反馈使用 `UiAlert` 或 toast。
- 页签不能在业务页重新拼 active 类；选择器不能退回原生 `select`；业务插件禁止直接导入 `reka-ui`。
- 新增视觉变体前先更新 `DESIGN.md`，再扩展公共组件 API。
- 界面文字默认不可选，输入值、编辑器正文、代码块与表格数据自动保留选择；额外可复制结果用 `select-text`，不要给整个工具页或操作栏开放选择。placeholder、按钮、页签仍不可选；不通过阻止全局 pointerdown/keydown/copy 来实现，以免破坏编辑、拖拽和终端选择。

## 4. 验收页面

应用工具列表中的“组件实验室”是独立交互测试页，覆盖按钮、表单、互斥筛选、折叠面板、菜单、徽标、页签、提示、空状态和弹窗。视觉验收覆盖亮色与深色主题、禁用态、加载态和窄窗口；无本地产品运行授权时交用户或 CI，不能用 DOM 单测代替视觉通过。

轻量行为回归位于 `src/core/ui/commonInteraction.test.ts` 和 `ContextMenu.test.ts`，覆盖禁用激活、动态尺寸、折叠状态保留、筛选键盘操作、进度边界、菜单焦点与避让。验证分工见[20](20-验证矩阵.md)。
