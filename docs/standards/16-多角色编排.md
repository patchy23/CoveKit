# 16 · 多会话与按需委派

> 单人项目默认一个 agent 串行完成开发与验证。只有用户或当前执行环境明确授权委派时才读本节；不用为角色形式增加 agent、分支或报告。

## 并行与工作区

- 仅委派可独立完成、能减少总工作量的具体子任务；依赖同一决策或同一文件的修改优先串行。
- 隔离目录或 worktree 按并行写入风险选择，不默认要求每个小任务创建分支。同一文件的修改明确由一个执行者负责。
- 单人不代表只有一个会话。用户手工修改或其它会话的未提交内容仍需保留；先确认归属，不自动 stash、reset、覆盖或一起提交。
- 接收结果时检查实际差异、接线及验证范围；异步任务的完成以工具状态为准，不按文件多久没变化推断。

## 跨会话接续

直接使用已有方案或简短摘要：目标、已完成、下一步、关键约束与未验证项。只给任务相关文件与入口，不复制整套规范，不另建交接包。

用户已裁决的范围和验证限制继续有效；未验证不能写成通过。没有可用委派工具就串行完成，不依赖特定助手的工具名或模型配置。
