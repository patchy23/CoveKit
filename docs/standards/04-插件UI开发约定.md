# 04 · 插件UI开发约定

## 必读摘要

- 新增或调整交互先读 [交互体验设计规范必读摘要](09-交互体验设计规范.md#必读摘要)，涉及可操作对象按 [右键菜单规则](09-交互体验设计规范.md#41-右键菜单的适用判断)判断是否接入已有动作。
- 设计 tokens 以 [DESIGN](../../DESIGN.md) 为准；基础控件从 `@/core/ui` 使用，凭证复合组件从 `@/core/vault` 使用。
- 基础 UI 不依赖业务 store、凭证服务或业务 IPC；平台操作与应用级反馈使用各自公共入口。
- 组件签名查 [公共组件API](../reference/02-公共组件API.md)，浏览器验证查 [浏览器与桌面UI验证](../guides/04-浏览器与桌面UI验证.md)，表单查 [表单排版约定](05-表单排版约定.md)，功能边界查 [产品范围](../product/01-产品需求.md#当前有效范围裁决)。
- 按改动读取本文相关专题；开发流程见 [开发工作流](../guides/01-开发工作流.md)，验证命令只在 [验证矩阵](../guides/02-验证矩阵.md) 维护。

## 公共组件契约

`src/core/ui/components.test.ts` 约束业务页面复用 UiButton、UiInput、UiSelect、UiCheckbox、UiTable 等公共控件。SSH 功能页签行“打开编辑器”的原生文字按钮是限定例外，仍须保留键盘、焦点和禁用语义。

- 单一动作使用按钮，可点击列表行优先使用 UiListRow。自定义可聚焦动作同时支持 Enter、空格与禁用态，行内按钮不重复触发行事件。
- 可编辑表格也使用 UiTable / UiTableCell，单元格组合输入控件；权限勾选矩阵等非数据表布局使用网格。
- 公共包装组件显式声明并下传 disabled、loading 及无障碍属性，不依赖可能被内部绑定覆盖的 attrs 透传。
- UiSelect / UiCombobox 选项 value 非空；“不选”使用非空哨兵并在回调映射。
- 应用表单默认关闭浏览器自动填充，Windows WebView 使用 `generalAutofillEnabled: false`；业务选项搜索和代码补全不受影响。
- 组件事件与父级监听须成对核对；新增、改名或删除 emit 时检查调用链，静态检查不能替代实际点击验证。

## 复杂工具页布局风格

工具页使用朴素多栏与边线分区，每栏自治局部标题和操作区，不额外套卡片外壳、阴影或重复的全局工具栏。内容区保留 `min-h-0` 等滚动边界，避免嵌套页签和多层滚动。

可收起的摘要栏必须保留恢复入口，收起按钮使用方向图标；关闭和收起不共用含混语义。同屏多栏底部状态区域定高对齐。图标使用项目 SVG 体系，不以 Unicode 字符代替。

配置类表单默认显示完成基本配置必需的字段，进阶字段收进“更多配置”；折叠保留已填值。布局改进先核对同类页面、字段分组、标签和对齐，不复制外部项目的整套视觉设计。

## 弹窗与下拉层级

- UiModal 默认不响应遮罩关闭，使用内置关闭按钮、Esc 或取消；确需点击外部关闭时显式声明。
- 下拉、菜单和提示层高于模态遮罩；复用公共层级，避免任意使用低 z-index。
- Teleport 到 body 的浮层根节点保留 `pointer-events-auto`，防止被模态层的 pointer-events 禁用。
- 框架设置使用整页显示，与工具工作区互切并保留后台页签状态；不注册成隐藏工具或业务页签。设置入口可切换打开和关闭状态。

浮层原语细节见 [Reka UI 约束](../reference/03-RekaUI原语参考.md)。

## UiTree 状态

展开集合独立于 computed 生成的节点数组，以稳定 ID 保存；更新时替换集合触发响应式。折叠后的深度过滤使用严格父子关系，不能把同深度边界判断写错。展开箭头、加载和焦点表现复用公共组件。

## 编辑器组件：一律走 UiCodeEditor / UiCodeDiff

文本编辑区域按档位选，禁止再自研或复制 CodeMirror 主题：

| 场景 | 用法 |
| --- | --- |
| 单行输入 | `UiInput` |
| 多行纯文本（无行号需求） | `UiTextarea` |
| 多行代码/配置（行号、高亮、缩进、查找） | `UiCodeEditor mode="minimal"`（吃掉全部旧 `LineNumberTextarea` 场景） |
| 完整编辑（查找替换 / 格式化 / 校验 / 补全 / 状态栏） | `UiCodeEditor`（默认 full 档） |
| 只读查看 | `UiCodeEditor readonly`（取代原 `CodeViewer`） |
| 差异对比 | `UiCodeDiff`（split 左右对照 / unified 内联，支持增删行统计及接受或拒绝变更） |

- **插件领域能力走注入口，不要在插件里 new EditorView**：`languageExtension`（方言高亮，如 SQL 方言）、`extraExtensions`（领域扩展，如数据库 ▶ 语句运行 gutter、Ctrl+点击表名）、`completionSources`（补全源）；`getCursor()` 取选区偏移。示例见 `plugins/database/SqlEditor.vue`。
- **主题唯一源** = `core/ui/editor/theme.ts` + main.css 的 `--cm-*`（浅深同名），暗色覆盖写在 main.css 全局 unlayered 区；领域样式（如 ▶ 按钮）随扩展用 `EditorView.theme` 自带，不要写进 main.css 全局区。
- **大文件降级由组件负责**（>512KB 关高亮/折叠/补全，>5MB 强制只读并 `emit('error')`），插件不要自己判断文件大小。
- **编辑器内的 Ctrl+F / Ctrl+H / Ctrl+S / Ctrl+G 已由组件拦截并 preventDefault**（否则 WebView2 弹自身查找栏或触发页面保存）；`Ctrl+W` / `Ctrl+Tab` 仍是工作区页签的，别在编辑器里抢。
- **编辑器选型**：CodeMirror 6 适合当前桌面工具的结构化文本与 SQL 编辑；模块化扩展便于控制体积和接入 DESIGN tokens。Monaco 的语言服务与 worker 配置会增加打包、CSP 和维护成本，当前没有足以引入第二基座的需求。现行决定见 [ADR-0004](../adr/ADR-0004-编辑器统一CodeMirror6基座.md)，不依赖本地选型记录。


## 编辑器与样式维护

缩进参考线按行的实际缩进绘制；折叠 gutter 使用 SVG，检查时跳过隐藏占位节点。自绘选区由 CodeMirror 主题统一决定，不叠加原生 selection 背景。修改样式前核对组件内置选择器的优先级，浅深主题均检查对比度和溢出。

编辑器统一契约由 `src/core/ui/editor/editorUnification.test.ts` 维护。工具通过公共注入口扩展语言与业务操作，禁止导入内部实现或创建第二套编辑器。

新增 core 子目录前检查同名单文件，避免 alias 优先解析旧文件。修改样式和模板后仅格式化本次文件；脚本中断后先核对实际落盘状态，避免重复修改。

主题调整同时检查浅深两种模式、聚焦与失焦选区、当前行与行号区、括号与搜索匹配、缩进参考线及横纵滚动条交角。样本覆盖注释、关键字、变量、属性、函数、字符串和数字，不用单一 JSON 样本代表所有语言。对比度与溢出结合计算样式和实际界面检查；临时对照页与外部主题调研留在本地，不复制第三方色值作为项目默认规则。验证范围见 [验证矩阵](../guides/02-验证矩阵.md)。

## 工具级设置

工具级设置统一在设置页渲染，只提供会影响用户工作方式的选择。当前保留 SSH 空闲断开时间与 FRP 配置目录；JSON 缩进固定两空格，SSH 意外断线自动重连，FRP 日志缓冲与下载源回退由应用处理。

FRP 本地客户端选择和外部文件引用由客户端管理入口负责，不恢复重复的路径或下载镜像设置。具体范围见 [FRP 设计](../product/01-产品需求.md#frp-客户端)。
