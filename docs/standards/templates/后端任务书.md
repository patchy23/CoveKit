## 命令契约要点（全部按 contracts.ts）
- 命令名 snake_case 与契约一致；`#[tauri::command(rename_all = "camelCase")]` 处理字段
- 错误统一 `Err(String)` 或 `{ ok: false, error: Some }`，禁止 panic
- 命令全部在 register() 里 `ipc_registry::register(&[...])` 入库（每条附中文说明）
- 事件名严格用契约定义（如 `ssh://terminal-data`），负载与契约类型对应
- 异步推送类（进度/数据流）：后台任务 + 事件 emit，命令立即返回

## 装配说明（重要）
- **不要改 `<src-tauri/src/lib.rs>` 的注册链**（集成者统一收口）
- 新依赖/新插件注册：把需要的装配代码片段（Cargo.toml 依赖行 + lib.rs 注册行 + 初始化方式）写入 `<docs/plugins/<id>/装配说明.md>`，集成者负责落库
- 分支：`feature/<id>-backend`（基于 main，不合并）
