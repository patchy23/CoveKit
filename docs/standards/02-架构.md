# 02 · 当前架构

> 本文只说明现行结构，2026-09-17 按实际装配、context 与 paths 核对。设计期路线和已废弃布局可由 Git 历史追溯；需求分册与历史批次不能替代当前源码。

## 现行架构与依赖方向

| 位置 | 职责 |
| --- | --- |
| src/main.ts、App.vue、src-tauri/src/lib.rs | 注册与启动、应用外壳、平台装配和退出委托 |
| src/features、src/stores | 页面协调与应用状态；持久化通过公开服务 |
| src/plugins/<owner> | 工具业务、界面与本 owner 状态；纯前端工具无需 Rust 模块 |
| src/core/ui | 无应用服务依赖的基础控件和 CodeMirror 编辑器 |
| src/core/vault | 凭证服务与复合 UI，经公开入口使用 |
| src/core/platform、feedback、lifecycle、ipc | 平台适配、反馈、生命周期和 IPC 公共能力 |
| src-tauri/src/framework | 数据上下文、路径、PluginDb、安全存储、凭证、设置、生命周期和装配 |
| src-tauri/src/plugins/<owner> | 协议、业务存储和后台资源；数据库内部分驱动、方言和代理 |

组装根组织应用和工具，共享基础层不反向依赖业务。owner 是业务边界，不是团队或服务部署单元；不为边界建立无用层级。跨 owner 不直读内部状态或数据表，共享行为通过公开契约。

基础 UI 内部使用相对具体组件路径，业务从 `@/core/ui` 导入；凭证复合组件从 `@/core/vault` 使用。前端 store 为缓存与展示，桌面持久化权威在 Rust；浏览器预览回退不能冒充桌面实现。

## 工具与 IPC 装配

前端工具自注册 manifest，由注册表和工作区装载。Rust 每个模块通过 `covekit_module!` 一份清单生成命令元数据和 handler；`covekit_routes!` 生成路由与启动校验，应用安装一次总 handler。

命令在本 owner 的 TS contracts/ipc 与 Rust DTO/command 间同步。传输、事件、取消和真实消费方的核对见[19](19-Tauri契约审计.md)，模块接入细则见[03](03-模块开发规则.md)。

## 数据与生命周期

### 3.1 存储布局与位置迁移

`framework/context.rs` 的 DataContext 在启动时固定空间、epoch 和 StorageLocation。当前没有 generationId，也没有 LegacyFlat/Partitioned 双布局枚举。持久化数据的位置由 `framework/paths.rs` 提供，模块不能自行拼根目录或重新选择空间。

| 数据 | 位置 |
| --- | --- |
| owner 数据 | <设备根>/spaces/<uid>/data |
| 凭证密文 | <设备根>/spaces/<uid>/vault |
| 空间业务日志，如 SSH 录制 | <设备根>/logs/<uid> |
| 可重建缓存 | <设备根>/cache/<uid> |

数据空间与设备目录分离，历史 owner 文件名通过显式映射保留。上下文 epoch 用来丢弃迟到结果，不是云同步 revision。维护操作共用 maintenance_guard，写冻结通过既有协调入口；不以新建上下文冒充切换完成。

应用运行日志与上述业务日志分开：新的[日志接入标准](05-Rust代码规范.md#7-日志约定)要求由 `framework::paths` 提供固定的系统应用日志目录，不随存储根迁移或空间切换，以便记录启动维护过程。该输出后端尚未接入，不能把它视为现有空间日志分区的迁移或重命名。

存储根不可用时显示恢复路径，不能静默回落并继续向错误位置写入。PluginDb 管理本地 SQLite 生命周期与事务迁移；代码复用既有迁移实现，不手写简化版本。导入导出与空间的有效边界见[数据传输要求](07e-数据空间与导入导出.md)。

页签关闭和应用退出是不同资源范围；生命周期由明确 owner 负责，组件卸载清理订阅/计时器，应用退出走统一协商。连接型数据库、SSH 和子进程不由基础 UI 管理。

## 安全与平台

凭证由系统 keyring 主密钥和 AES-256-GCM 文件保存，失败不得生成新密钥伪装恢复。数据兼容、错误反馈和凭证保护不因单人开发而弱化。Windows/macOS 能力差异见[09](09-平台能力矩阵.md)，设计 tokens 见[DESIGN](../../DESIGN.md)。

UI、Rust、测试与提交规则分别由相关专题维护，本文不复制执行清单或命令。

## 已确认框架行为

2026-09-14 用户裁决，2026-09-18 从任务材料提炼：存储位置迁移不合并非空目标，只允许恢复上次中断的提交；恢复页动作重启后生效。设置保存失败回滚且不保留草稿。设置层运行期拒绝结构化明文 secret，不再增加重复的源码级守卫。组件实验室仅在开发构建注册。关闭主窗口最小化到托盘属于设计行为。

这些规则不授权恢复已取消的旧数据兼容迁移；旧数据边界见[数据传输要求](07e-数据空间与导入导出.md)。
