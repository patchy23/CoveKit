# 02 · SSH远程管理

SSH 工具围绕服务器连接组织终端、文件、隧道、监控、服务、进程、Docker 和 Compose。本文维护 SSH 的具体行为，文件与编辑器约束见[文件工作区](#文件工作区)。

## 连接与认证

- 服务器配置与运行连接分离；支持服务器分组、搜索和多个连接工作区。配置修改不隐式覆盖已有连接的运行状态。
- 认证支持密码、私钥及凭证库引用；手工认证支持本地明文保存、不保存或保存到凭证库，新建手工认证默认本地保存。不保存的秘密只用于当前工具会话，关闭后释放。
- 未知主机必须由用户确认，已保存主机密钥变化不得静默接受。展示算法与 SHA-256 指纹，拒绝、取消和不匹配的错误可感知。
- 取消、删除或重配后的迟到连接结果必须失效并回收；主动断开不自动重连。意外断线重连不得恢复已明确关闭的工作区。
- 连接、单终端、传输、编辑器、隧道与日志任务各有资源归属；关闭连接统一协调，禁止仅移除界面而遗留任务。

## 终端与运维

xterm.js 承担终端渲染，尺寸、搜索、复制粘贴和日志操作按当前页签作用。终端输出不因切换工具丢失；用户主动记录日志与普通应用日志分离，不把会话正文写入应用日志。

监控仅在相关页面活动且连接可用时采样，速率由连续样本差值计算，读取失败显示中断与旧值状态，不显示为零。服务、进程、Docker 和 Compose 操作依赖远端系统能力；缺失命令或权限时给出明确原因，不自动安装依赖。

服务与进程默认隐藏系统项，各自保存开关并显示隐藏数量；未知来源或自定义服务保留，不按 root 用户一律隐藏进程。搜索与状态筛选叠加。停止、重启、删除、结束进程等动作必须表达真实目标和影响；日志窗口关闭后释放后台任务。

隧道绑定所属连接，监听地址、端口、目标和状态必须可见。建立失败与 SSH 断开分别反馈，结束连接时释放转发资源。应用不因演示或恢复草稿而自动连接服务器或执行命令。

## 文件工作区

- 编辑状态归当前连接所有，编辑器与日志窗口共同挂载在 SSH 工具根层；功能页签右侧打开或恢复非模态弹窗，不受文件内容区裁剪，切换功能或连接不隐式最小化；支持最小化、最大化和调整大小，保留多文档草稿。关闭窗口检查未保存文件；页签溢出由公共下拉收纳。
- 仅 SSH 文件编辑器支持“在独立窗口打开”和“移回主窗口”，其他弹窗保持工具内形态。独立窗口复用现有 SSH 会话，不重新认证；保留多文档草稿、活动页签、目录及光标/滚动位置，撤销历史不跨窗口迁移。独立窗口接管编辑期间，主窗口只保留同步草稿；移回须确认接收后再关闭原窗口。关闭独立窗口、连接或应用时检查未保存内容；连接断开保留草稿，恢复后可继续保存。
- 文件底部右侧书签与传输为互斥点击浮层。书签紧凑搜索、行尾删除，不提供右键菜单；关闭传输浮层不停止任务。
- 本地栏默认收起、首次展开加载；默认使用用户下载目录设置，否则依次回退到系统下载、文档、用户目录。路径保留 Windows/macOS 原生语义。
- “下载到本地”单文件另存为并默认原名，目录或多选一次选择目录；跨栏拖拽只传起点行，直接使用本地栏目录。下载及重试允许覆盖同名普通文件，目录合并；文件与目录类型冲突明确报错。
- 下载目标全部预先入队，每连接最多两项传输，同目标及父子路径串行；取消全部覆盖等待、准备和运行阶段。目录作为一个任务汇总；临时文件写完再替换，失败或取消保留原文件，合并目录不删除额外文件。任务行紧凑展示名称与状态，详情支持复制，书签悬停显示完整路径。
- 主机终端“查看文件”按需打开对应目录。Linux 绑定登录 shell 进程并验证会话身份；不支持时可使用经过主机校验的 OSC 7 报告，否则明确失败。嵌套 SSH、容器及 tmux 内部目录不属于主 shell 的目录保证。
- 远端 ZIP、单文件 GZ、TAR.GZ/TGZ 创建、解压与目录预览要求 Python 3.8+ 标准库和 POSIX 进程监督能力，不自动安装依赖。压缩/解压默认不覆盖，写临时位置后提交，取消等远端确认，断线结果不明时不得显示成功。
- 预览不下载完整归档；TAR.GZ 目录需要顺序扫描。条目上限 10 万，ZIP 中心目录上限 64 MiB；不支持加密包、链接/特殊文件提取及包内修改。未知 GZ 原始大小不伪造。


## 服务器 CSV 批量管理

服务器列表菜单支持批量导入与导出，分组菜单可指定分组。导入支持 UTF-8 CSV 和粘贴的制表符表格，最大 2 MiB、5000 行。先映射字段、预览校验，再确认密码保存方式；不自动连接。

字段为 `name,host,port,username,password,group,remark`。主机与用户名必填，名称为空时取用户名与主机、端口为空时取 22。密码不裁剪首尾空白，预览只显示是否提供。仅导入密码认证；导出文件中的密钥认证行明确跳过。

重复依据主机、端口、用户名，默认跳过，可更新唯一匹配项或新增。文件内部重复、无效端口及多重匹配更新不会静默覆盖。分组可按名称匹配/创建，或统一指定现有分组。失败报告只含行号、状态和固定原因，不含密码。

导入前明确选择：本地明文保存、凭证库、不保存。更新时空密码保留原认证；提供新密码写入凭证库时创建独立凭证，不修改共享凭证，配置保存失败尝试清理新凭证，清理失败可见，不回退明文。

导出范围包括全部、分组、手选服务器。默认不含密码，显式勾选后只写出本地保存的密码；凭证库密码与私钥始终不导出。CSV 带认证类型和密码来源标记，密码直接由后端写入用户选择的文件，不经过配置列表。密码 CSV 属于本地明文文件。

## 验证重点

覆盖连接取消与迟到成功、主机密钥拒绝、断线重连、文件传输取消、同目标串行、远端修改冲突、未保存关闭和跨窗口草稿交接。协议测试不能替代真实 SSH/SFTP 服务验证；执行范围见[验证矩阵](../guides/02-验证矩阵.md)。
