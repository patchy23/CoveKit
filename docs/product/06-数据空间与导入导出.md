# 06 · 数据空间与导入导出

> 本文规定数据空间、凭证和导入导出的产品边界；实现与平台验证状态分别记录。

## 空间与设备

本地使用不依赖登录。空间 uid 是本地数据容器身份与导出包来源标识，不是账号、团队权限或云同步 revision。当前不做登录、云端服务、网络同步、自动上传或云端密钥托管。

数据使用 `spaces/<uid>/`，没有 generations 目录或 generationId。空间数据、设备配置、日志与缓存分离，路径由唯一 DataContext 与 framework::paths 提供；设备路径、客户端安装绑定和运行会话不随包搬移。

<a id="旧数据边界"></a>

不提供旧数据兼容与迁移层：旧扁平目录、旧格式密文、SSH localStorage 存量和旧 pbvault 不读、不搬、不删，留在原位由用户处理。不要恢复 LegacyFlat、default/1 别名或已删除的布局迁移引擎。PluginDb schema 版本迁移仍用于应用后续演进，不受此裁决影响；当前格式的存储位置迁移也不属于旧布局兼容。

实现核对：Vault 目前仍有当前空间根下 `vault.dat` 的旧位置回落分支，与上述要求尚未完全一致。具体触发条件见 [Vault 存储说明](06-数据空间与导入导出.md#凭证库契约)；不能据此宣称旧布局兼容已完全移除，也不将其扩大为支持承诺。

## 普通数据与凭证

除了凭证，其他内容默认按普通数据处理；需要秘密保护的内容由用户维护为凭证。API 原文、SQL、FRP TOML 和 DNS 手工配置按选择传输，不增加敏感内容标记或额外危险确认；传输包仍保持加密。

Vault 与数据库 namespace 的结构化凭证内容不随数据包导入导出，目标空间重新补录；不按同名或同 ID 偷绑本地凭证，也不跨 uid 复用凭证。空间凭证密文以 uid 作为 AES-GCM AAD 绑定。密钥读取失败不能生成新密钥冒充恢复成功。

现存实现差异：`src-tauri/src/plugins/frp/transfer.rs` 的导入规划仍要求携带所引用的 `vault.credentials`，并按导入映射重写引用；未携带时会拒绝导入。这与上述凭证不随包传输的裁决不一致，不能宣称引用凭证的 FRP 配置已支持在目标空间重新补录后导入。此处记录待修正行为，不将其扩大为凭证传输承诺。

## 选择、身份与合并

按逻辑数据集选择导出、隔离导入为新空间，或预览后合并到当前空间；不是整库复制或覆盖协议。记录使用稳定身份，依赖引用先解析并重映射；重复导入不得无故重复创建或复活已删除记录。未选数据集必须保留，覆盖也仅针对选中数据集。

偏好只传白名单中的空间字段，不覆盖设备设置。数据库仅传连接元数据、收藏和历史 SQL，不搬凭证或 SQLite 本机路径。FRP 元数据与文件原文分选，原文依赖元数据；导入只写空间管理副本，覆盖原文不得删除外部用户文件，仅覆盖元数据不得删除未选原文或本机客户端绑定。

## 提交与恢复

预览和提交核对源修订，冲突不静默覆盖。合并导入原地事务提交，不要求重启：SQLite 使用 IMMEDIATE 事务，文件使用原子 rename；提交后定点刷新。提交前等待在途数据库访问、冻结写入、制作包含 WAL 数据的快照，失败恢复并释放冻结。导入前快照保留最近 3 份，供用户恢复；隔离导入仍使用 staging 加 rename。

导入不执行 SQL、不连接数据库、不发送 HTTP/WS 请求、不启动 FRP 进程；已有运行会话继续由原生命周期管理。前后端传输字段及 owner 适配契约以源码为准，公共传输层不直读 owner 内部状态。

## 凭证库契约

Vault 是框架能力，设置页以弹窗承载凭证管理，公共选择器位于 `src/core/vault/`。连接配置归工具，秘密通过凭证标识引用并在后端解析；列表返回脱敏摘要，主动显示或复制才调用 `vault_reveal`。

凭证密文位于当前空间 vault 分区的 `vault.dat`，AES-256-GCM 使用新 nonce，AAD 绑定空间 uid。系统密钥库 service 为 `com.patchyx.covekit.<空间 uid>`、account 为 `vault-master-key`。首次写入主密钥须回读校验，失败可保存收紧权限的本地降级密钥文件并明确展示保护状态。已有密文必须由候选密钥认证通过才能解锁，不得生成新密钥覆盖；原子替换和备份恢复按可解密、可解析的内容择版。

`vault_credential_references` 汇总各 owner 的引用与未知扫描状态；`vault_delete` 重新核对当前引用，不能把扫描失败计为零或沿用已经变化的确认计数。删除连接不连带删除共享凭证，引用失效不静默回退其他认证来源。

独立 `.pbvault` 备份使用一次性密码经 Argon2id 派生密钥后加密，格式版本严格校验；合并按同 id 跳过，覆盖替换库内容。损坏原密文在恢复路径留档。Vault 不防御已登录当前系统账户的恶意进程，本地降级密钥不等于系统密钥库保护；不提供主密码解锁、Stronghold 或凭证共享。

现存实现差异：`src-tauri/src/framework/vault/store/paths.rs` 的 `resolve_vault_dir` 在 vault 分区不存在且当前空间根有 `vault.dat` 时仍回落到空间根，与旧数据边界要求尚未完全一致。调整前核对恢复调用链和已有数据；此分支不构成新增兼容承诺。
