# 01 · 产品需求

CoveKit 面向开发者和个人服务器维护者，提供本地优先的桌面工具工作区。产品目标是覆盖日常远程运维、接口调试、数据库操作与数据处理；不以工具数量或未经验证的平台承诺作为能力说明。

## 当前有效范围裁决

- 桌面平台为 Windows 和 macOS。文件占用、端口占用是 Windows 专属工具，macOS 明确显示不支持；不考虑 Linux 桌面产品支持。SSH 连接 Linux 服务器不受此限制。
- 本地功能无需 CoveKit 账户；当前不提供登录、云服务、云同步、自动上传或云端密钥托管。
- 工具通过仓库内注册表接入，不提供动态第三方插件市场。各工具业务独立，共享能力经公开契约复用。
- 全局唤起快捷键不在当前范围；跨工具数据传输、按 owner 自动淘汰缓存和无状态工具暂缓。
- 接口调试保持 HTTP、SSE、原始 WebSocket 的轻量范围；协议在创建请求时绑定，详见[接口调试](03-网络与调试.md#8-接口调试)。
- 数据库面向开发与测试，允许可靠主键单表编辑、CSV 导入、完整只读导出、SQL 文件及草稿、EXPLAIN 和测试 SQL 模板，详见[数据库范围](05-数据与媒体工具.md#13-数据库工作台开发与测试范围)。
- SSH 保留凭证库认证；手工密码和私钥支持本地明文保存、不保存、保存到凭证库。新建手工认证默认本地保存，直接写本机 SSH 数据库，不依赖 Vault。已有凭证引用不自动迁移。编辑留空保留匹配连接参数的本地认证，填写则覆盖；改变主机、端口、用户名或认证类型需重新输入，删除服务器同步清理本地认证。
- 普通 SSH 逻辑配置导出不含本地认证，完整数据目录副本包含该数据库；CSV 密码导出须显式选择，详见[SSH 批量管理](02-SSH远程管理.md#服务器-csv-批量管理)。日志和 IPC 元数据不得泄露秘密。

## 文件占用查询

输入、选择或拖入单个文件，展示使用该文件的 PID、应用与服务名称、可读取的程序路径；支持刷新、复制信息和打开程序目录。确认后可关闭选定进程，须说明未保存内容可能丢失。

后端重新核对文件使用关系、PID 与启动时间；拒绝关闭自身、系统保留进程和关键进程，不自动提权，成功后刷新。不支持目录、批量查询或直接关闭文件句柄；查询结果不等于阻止删除的判定，空列表不保证没有占用。端口占用另见[端口查询范围](03-网络与调试.md#15-本机端口占用查询)。

## 应用资源监测

左侧底部菜单组上方的独立统计栏显示内存与 CPU，统计栏与菜单以细分隔线和间距区分；主题切换与设置保持相邻，悬停查看非模态详情，点击保持展开；设置提供默认关闭的总开关及支持工具多选。多选只控制工具详细统计，应用进程合计不因取消某工具而扣减。停用停止采样、清空会话统计并保留选择，不结束业务连接或任务。工具级统计为统一 IPC 的次数、失败、在途与响应耗时，以及接入 scope 的作用域、订阅和定时器；不把响应耗时或数据大小冒充工具独占 CPU、总内存。按 owner 缓存清理及无状态工具淘汰策略仍暂缓。

资源监测采用串行只读采样，成功后约一秒再取下一帧；收起侧栏、切换工具不停止会话，实际间隔受 WebView 后台调度影响。首次样本没有 CPU 差值；读取失败保留旧值、标明中断与上次成功时间。Windows 对本进程及按父子关系、启动时间核对的后代统计私有工作集、完整工作集、私有提交、CPU、线程和句柄；侧栏内存、峰值及进程分类明细统一采用私有工作集，不重复累计共享页。详情直接列出私有工作集、完整工作集与私有提交量，以总览、内存指标、进程明细和工具统计分区展示，不折叠内存指标、不与侧栏口径混用；系统不支持私有工作集读取时显示不可用，不回退为完整工作集或零。macOS 统计本进程和可归属子进程 RSS、CPU，WebKit XPC 未完整覆盖，侧栏标注“仅部分进程”；不可用字段不显示为零。资源数据只保留当前样本、前次采样计算所需数据及本次峰值，不保存业务正文或采样历史文件。平台验证状态见[平台能力矩阵](07-平台能力矩阵.md)。

## Codex 重置消息

- 单栏展示 AIHOT 整理的 Codex 重置消息，使用固定的 `https://aihot.news/api/v1/codex-resets` 公共接口；展示中文来源帖子、来源链接、本地时间和限定状态，保留适用范围与原预告的语义，不把过期预告视为完成。以完整快照替换旧数据，撤回事件及时移除。
- 支持未读筛选、全部已读及行内详情。首次获取历史消息建立已读基线；同一事件的内容、状态或证据变化视为更新，抓取时间变化不产生未读消息。
- 手动刷新直接应用；自动更新仅在工具页面可见时每五分钟检查，新消息先提示用户点击应用，避免打断阅读。缓存及已读记录保存在当前数据空间的 `codex_news.db`。
- 网络失败保留缓存并显示错误；消息源核验时间未知、过期或监控延迟须明确提示。旧 SaveMeTibo 缓存保留来源标记，新源首次成功后整体替换并建立已读基线。当前不提供通知、后台监控、个人额度查询或账户操作。

## 通用行为与验收

修改、导入、保存、取消与关闭必须有可感知结果；失败不得显示成功。切换页签保持所属工作状态，关闭单页签与关闭应用的资源清理范围不同。数据迁移、密钥失败、并发写入与恢复须覆盖故障路径，不以正常路径测试代替。

验证遵循[测试与走查](../standards/06-测试与走查.md)和[验证矩阵](../guides/02-验证矩阵.md)。规格描述不等于已通过真实服务或平台验证。

## FRP 客户端

仅管理本机 frpc，支持客户端版本选择、下载与引用外部客户端，配置表单/源码编辑、校验、启停和日志；不管理 frps，不承诺应用退出后后台常驻。未保存配置先保存再切换模式、校验或启动，运行中修改需重启生效。表单重建 TOML 可能丢失注释，需要保留注释时使用源码模式；未覆盖的嵌套字段须保留。

手工 Token 按配置文件明文保存；Vault 引用通过保留命名空间的环境模板写入档案，Rust 解析后仅注入子进程环境，不把秘密写入档案、临时配置或 IPC，输出按 Token 脱敏。引用失效、类型不符或密钥不可用时明确失败，不回退空 Token。档案删除不删除共享凭证，引用扫描失败按未知处理。元数据导出不携带配置正文或秘密；凭证传输边界及现存实现差异见[数据空间与导入导出](06-数据空间与导入导出.md#普通数据与凭证)。

已删除配置从回收站恢复到原目录，阻止覆盖同名档案，不自动启动；不承诺历史元数据快照。客户端下载使用上游发行资产，缺少校验文件时说明未强校验，不自动替换运行中的版本。进程仍有 PID 时保留停止入口，错误随最新运行快照更新。

FRP 诊断接入应用统一日志，脱敏后记录关键生命周期和失败，不记录完整子进程输出或重复轮询；文件输出与轮转由 `lib.rs` 统一配置，规则见[日志标准](../standards/03-Rust代码规范.md#7-日志约定)。
