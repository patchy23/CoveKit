# 05 · 数据与媒体工具

本文维护格式转换、文字转语音和数据库的具体行为。数据库章节保留稳定锚点，产品范围与实现契约在本文分节维护。

## 格式转换

JSON、XML、时间戳、Base64 组成同一工具的四个子页签。切换保留各面板输入，输入经 300ms 防抖自动转换，模式和方向切换立即重算；空输入清空结果，不按错误处理。

JSON 与 XML 提供格式化、压缩和校验反馈；JSON 格式化缩进固定 2 空格。时间戳提供时间转换；Base64 按 UTF-8 文本编解码，遇到不能安全显示的二进制内容明确报错，不产生乱码结果。工具不上传输入正文。

当前不包含独立 YAML/CSV 转换、JWT、哈希、文本对比或正则测试工具；这些旧设想不构成现行开发要求。

## 文字转语音

使用 Microsoft Edge 在线语音服务，将输入文本发送给第三方进行合成，结果缓存为 MP3 并可播放、下载。支持内置中文音色、语速和音调调节，单次文本限制以实际校验为准。

合成按请求显示连接、发送、接收、写盘、发布阶段与最近进展时间。连接 30 秒或音频接收 120 秒没有进展时提示停滞，不自动终止；用户始终可以继续等待或取消。取消当前合成保留输入和此前已呈现音频的播放、下载源。

未发布音频按请求写入持有独占存活锁的随机实例目录。新实例初始化时仅回收能取得存活锁的失活实例，不按文件年龄或 PID 判断；发布后的 MP3 在实例目录外保存。缺少实例锁的旧版散落临时文件不自动删除。

输入为空、文本超限、网络失败、缓存写入失败应分别可感知；失败不得返回可播放结果。下载使用用户选择的目标，不向日志记录正文。长文本分段队列、音频编辑、预设管理和历史面板不在当前范围。

## 13. 数据库工作台：开发与测试范围


### 13.1 决策

数据库工具按日常开发、测试需求完善执行正确性、交互和紧凑 UI。优先 MySQL、PostgreSQL、SQLite、Redis；Oracle 保留 agent 适配，驱动与实机验收单列。允许单表数据编辑，不延伸为数据库管理平台。

### 13.2 功能范围

- 连接管理、凭证引用、对象树、表结构与表数据浏览。
- SQL 编辑执行、事务与取消，多结果查看、EXPLAIN、可审阅的测试数据 SQL 模板。
- 文件打开与另存、草稿恢复、查询历史与收藏。
- 服务端筛选与排序、单表编辑、CSV 导入与查询结果导出。
- Redis 游标扫描、加载更多、ACL/TLS 与有界类型预览。
- 既有建库、DDL、索引和表管理。

### 13.3 可靠性要求

上述能力的会话、数据与资源约束统一见[数据库实现契约](#数据库实现契约)。支持矩阵由实际驱动决定；达梦未实现前不在新建列表出现，agent 类型选择时立即显示依赖状态。无实机条件不宣布对应驱动或平台通过；协议夹具、单测和真实 UI 验收分别记录。

### 13.4 UI 原则

内容优先，基础控件优先 xs、工具栏 compact，SQL 新建入口固定可见；右侧摘要按需折叠。编辑页保留独立撤销、光标与滚动。新建连接复用公共凭证组件，高级选项收起。后台不轮询整棵对象树，大结果不深度响应式代理。状态、错误、限制及下一步操作必须可见。

### 13.5 明确不新增

不新增数据库类型、ER 图、数据建模、结构同步、通用数据库迁移、DBA 监控、团队连接共享或批量数据修复平台。不内置数据库专属 SSH 隧道；需要时使用 SSH 模块公开能力创建本地转发端口。各驱动详细边界见[数据库设计](05-数据与媒体工具.md#数据库实现契约)。

## 数据库实现契约

SQL 支持选区、当前语句和脚本执行，并分别呈现多结果。每个 SQL 页签拥有独立工作会话，同页串行、跨页可并发；连接、数据库/schema 和页签共同确定请求与结果归属。断开、删除、重配或关闭使迟到结果失效并释放会话。事务中禁止切换目标；生产连接默认只读，后端拒绝只读连接的未知写语法；建库、DDL 和表管理也遵守同一保护。高危操作展示目标与 SQL 摘要，确认绑定冻结的 SQL、目标与请求。

取消响应不等于执行结束，驱动必须收尾协议；提交结果未知不能宣称回滚或自动重试。MySQL 使用实际连接标识取消，PostgreSQL 使用 CancelToken，SQLite 使用 InterruptHandle；Redis 已发送命令不能撤销，agent 必须支持兼容协议与会话标识。返回展示预算不能靠篡改 SQL 或跳过协议收尾实现。

结果类型区分 NULL、空串、文本 NULL、数值、时间、JSON 与二进制，复制与导出保留大整数、高精度小数的精度与原值。IPC 有完整类型值时只传一份正文，显示行由入口复用原字符串还原，兼容仅提供显示行的驱动。单表编辑需要明确来源、完整原列及主键，不开放 JOIN、聚合、CTE、别名或脚本结果编辑；修改先留在页签，确认保存后在独立短事务中以原值校验并发，任一冲突整批回滚。活动 SQL 事务先结束再重查；无法证明来源时保持只读。

已加载大结果的全文筛选在可取消 Worker 中执行。后台按版本复用不可变结果快照，关键词变化不重复传输正文，行修改只传变化行；小结果保持直接筛选。计算期间显示状态，复制与导出等待发起时对应版本，版本改变则取消该次操作。工作器失败明确显示，不把大筛选退回主线程；闲置一分钟释放后台快照。

表浏览与 SQL 结果采用显式服务端分页，默认每页 100 行；页大小提供 100、200、500、1000 四档，选中后立即重取当前页，不提供应用按钮或单独补读当前页的操作。可输入页码并跳到首页或尾页；尾页只在显式请求时按筛选条件或执行时 SQL 精确计数。翻页读取目标页并替换当前页，不依赖前端累计的行数，滚动不自动加载；超出数据范围时保留原页并提示。未保存的单元格草稿阻止翻页与调整页大小。表数据支持组合条件、NULL/IN/范围筛选、排序与 SQL 预览，值通过参数绑定传递，禁止拼接；默认按主键稳定排序，目标页按偏移读取；无主键时说明顺序可能变化。不能安全重放的 SQL 游标只允许在已缓存页间跳转，继续读取仍使用原执行流，不能统计或直达尾页。CSV 导入先预览与字段映射，提交绑定文件指纹并事务执行。已加载结果导出与重新执行查询的完整导出分开说明，后者不保证与网格同一快照；失败或取消只清理本任务临时文件。

可验证为单条安全只读 SELECT、且不在显式事务中的 SQL 按执行时 SQL 请求目标页，并保留用户原有 LIMIT/OFFSET 语义；每次只保留当前页，不因累计行数或页数停止翻页。不能安全重放的结果沿用原生游标，只能沿原执行流前进；前端最多保留最近 5 页并服从共享 64 MiB 结果预算，裁掉的旧页不可返回，界面说明限制且不自动重放 SQL。更改游标页大小沿当前游标读取，不重新执行 SQL；请求已裁掉的旧页时保留当前结果并说明限制。锁定查询、未知函数、写语句与多语句脚本不走安全分页；外置 agent 尚无续读协议时保留单次响应上限并明确截断。游标结果通道绑定连接与页签，关闭、断开、换查询、维护切换或闲置超时均释放，协议收尾失败明确报告会话失效。结果正文通过 Canvas 只绘制可见行列，DOM 表头显示字段名与数据库实际数据类型，无法确定时明确显示未知；列宽操作保留 DOM。双击、Enter 或 F2 在当前单元格临时叠加一个输入控件并暂存修改，结束编辑或单元格离开视口后销毁控件，页签草稿继续保留；保存并提交仍是独立动作。单页结果上限为 32 MiB，游标页窗口沿用共享结果预算；长字段只渲染短预览，详情、复制与导出保持原值，隐藏结果区不继续挂载网格。

工作区草稿只保存文档、目标与编辑状态，不恢复连接、执行、结果或活动事务。关闭和刷新保护未保存修改、活动事务与运行任务。Redis 新建连接默认使用 db0，不配置单一数据库索引；目录按后端返回的逻辑库清单显示各库，展开后才用带库作用域的 SCAN 懒加载键，键详情与命令编辑器保持该库上下文。库清单受权限限制时显示后端警告，不伪造全量库列表。Redis 使用有界预览，不能安全往返的键或值须明确处理；agent 协议夹具不能替代真实数据库验证。结果按行、字节与时间限制，具体限额由实际契约和测试维护，界面达到限额须说明截断或拒绝原因。

连接密码通过公共凭证库保存和后端解析；修改或删除连接不删除共享凭证。空密码输入保留原值，清空是显式操作；旧密码迁移需写入、回读校验再保存引用，失败保留恢复条件。数据库图标不代表对应驱动已实现。
