# 05 · 数据与媒体工具

本文维护格式转换、文字转语音和数据库的具体行为。数据库章节保留稳定锚点，产品范围与实现契约在本文分节维护。

## 格式转换

JSON、XML、时间戳、Base64 组成同一工具的四个子页签。切换保留各面板输入，输入经 300ms 防抖自动转换，模式和方向切换立即重算；空输入清空结果，不按错误处理。

JSON 与 XML 提供格式化、压缩和校验反馈；JSON 格式化缩进固定 2 空格。时间戳提供时间转换；Base64 按 UTF-8 文本编解码，遇到不能安全显示的二进制内容明确报错，不产生乱码结果。工具不上传输入正文。

当前不包含独立 YAML/CSV 转换、JWT、哈希、文本对比或正则测试工具；这些旧设想不构成现行开发要求。

## 文字转语音

使用 Microsoft Edge 在线语音服务，将输入文本发送给第三方进行合成，结果缓存为 MP3 并可播放、下载。支持内置中文音色、语速和音调调节，单次文本限制以实际校验为准。

输入为空、文本超限、网络失败、缓存写入失败应分别可感知；失败不得返回可播放结果。下载使用用户选择的目标，不向日志记录正文。长文本分段队列、音频编辑、预设管理和历史面板不在当前范围。

## 13. 数据库工作台：开发与测试范围


### 13.1 决策

数据库工具按日常开发、测试需求完善执行正确性、交互和紧凑 UI。优先 MySQL、PostgreSQL、SQLite、Redis；Oracle 保留 agent 适配，驱动与实机验收单列。允许单表数据编辑，不延伸为数据库管理平台。

### 13.2 功能范围

- 连接管理、凭证引用、对象树、表结构与表数据浏览。
- SQL 编辑执行、事务与取消，多结果查看、EXPLAIN、可审阅的测试数据 SQL 模板。
- 文件打开与另存、草稿恢复、查询历史与收藏。
- 服务端筛选与排序、单表编辑、CSV 导入与查询结果导出。
- Redis 游标扫描、加载更多、ACL/TLS 与有界类型预览。
- 既有建库、DDL、索引和表管理。

### 13.3 可靠性要求

上述能力的会话、数据与资源约束统一见[数据库实现契约](#数据库实现契约)。支持矩阵由实际驱动决定；达梦未实现前不在新建列表出现，agent 类型选择时立即显示依赖状态。无实机条件不宣布对应驱动或平台通过；协议夹具、单测和真实 UI 验收分别记录。

### 13.4 UI 原则

内容优先，基础控件优先 xs、工具栏 compact，SQL 新建入口固定可见；右侧摘要按需折叠。编辑页保留独立撤销、光标与滚动。新建连接复用公共凭证组件，高级选项收起。后台不轮询整棵对象树，大结果不深度响应式代理。状态、错误、限制及下一步操作必须可见。

### 13.5 明确不新增

不新增数据库类型、ER 图、数据建模、结构同步、通用数据库迁移、DBA 监控、团队连接共享或批量数据修复平台。不内置数据库专属 SSH 隧道；需要时使用 SSH 模块公开能力创建本地转发端口。各驱动详细边界见[数据库设计](05-数据与媒体工具.md#数据库实现契约)。

## 数据库实现契约

SQL 支持选区、当前语句和脚本执行，并分别呈现多结果。每个 SQL 页签拥有独立工作会话，同页串行、跨页可并发；连接、数据库/schema 和页签共同确定请求与结果归属。断开、删除、重配或关闭使迟到结果失效并释放会话。事务中禁止切换目标；生产连接默认只读，后端拒绝只读连接的未知写语法；建库、DDL 和表管理也遵守同一保护。高危操作展示目标与 SQL 摘要，确认绑定冻结的 SQL、目标与请求。

取消响应不等于执行结束，驱动必须收尾协议；提交结果未知不能宣称回滚或自动重试。MySQL 使用实际连接标识取消，PostgreSQL 使用 CancelToken，SQLite 使用 InterruptHandle；Redis 已发送命令不能撤销，agent 必须支持兼容协议与会话标识。返回展示预算不能靠篡改 SQL 或跳过协议收尾实现。

结果类型区分 NULL、空串、文本 NULL、数值、时间、JSON 与二进制，复制与导出保留大整数、高精度小数的精度与原值。单表编辑需要明确来源、完整原列及主键，不开放 JOIN、聚合、CTE、别名或脚本结果编辑；修改先留在页签，确认保存后在独立短事务中以原值校验并发，任一冲突整批回滚。活动 SQL 事务先结束再重查；无法证明来源时保持只读。

表浏览使用服务端分页、组合条件、NULL/IN/范围筛选、排序与 SQL 预览，值通过参数绑定传递，禁止拼接；分页保持稳定排序，无主键时说明顺序可能变化。精确计数独立触发。CSV 导入先预览与字段映射，提交绑定文件指纹并事务执行。已加载结果导出与重新执行查询的完整导出分开说明，后者不保证与网格同一快照；失败或取消只清理本任务临时文件。

工作区草稿只保存文档、目标与编辑状态，不恢复连接、执行、结果或活动事务。关闭和刷新保护未保存修改、活动事务与运行任务。Redis 使用 SCAN 和有界预览，不能安全往返的键或值须明确处理；agent 协议夹具不能替代真实数据库验证。结果按行、字节与时间限制，具体限额由实际契约和测试维护，界面达到限额须说明截断或拒绝原因。

连接密码通过公共凭证库保存和后端解析；修改或删除连接不删除共享凭证。空密码输入保留原值，清空是显式操作；旧密码迁移需写入、回读校验再保存引用，失败保留恢复条件。数据库图标不代表对应驱动已实现。
