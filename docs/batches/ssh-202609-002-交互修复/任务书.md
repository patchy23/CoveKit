# SSH 交互修复任务书

2026-09-17 用户明确提出六项修复与优化，本批按该范围实施。

1. 搜索框内右侧放添加连接按钮；指纹管理移到侧栏底部文字入口，所有列表状态可达。
2. 远程路径粘贴保持 `/`，本地 Windows 路径使用 `\`，不再混用转换分支。
3. 终端最后一行完整显示，初始布局、字体加载、切换页签与尺寸变化后同步 PTY。
4. 终端滚动条可原生鼠标拖动，文本选择和终端鼠标上报保持可用。
5. 按用户后续要求，关闭全部会话移入连接标签右键菜单“关闭全部”，移除右上角按钮，沿用原有关闭确认和资源清理。
6. 服务列表按名称/描述搜索；查看 systemd unit 原文及 drop-in 覆盖配置，只读展示。

不修改远程配置，不自动提权，不升级终端依赖，不更改会话关闭策略。执行与验证状态见[实现方案](实现方案.md)。
