# SSH 交互修复实现方案

起始 HEAD：`685394b0ca7c1e21f357189e51016520c80f4484`。用户已明确授权[六项范围](任务书.md)，常规入口位置按用户给出的建议实施。

## 根因与实现

- `ServerList` 的 180px 侧栏顶部并排两个按钮，挤压搜索。公共 `UiSearchInput` 增加可选尾部动作槽，保留清空搜索；指纹管理改底部文字入口。
- `PathBreadcrumbs.submit` 把“远程且已有前导斜杠”误落到 Windows 转换分支，拆开两类路径归一化。
- FitAddon 以父元素 CSS 高度计算行数，没有扣父容器 padding；现有补偿只减一行且读到的渲染尺寸可能滞后。挂载区改为外层内边距、内层无内边距；按 fit 提议计算尺寸，渲染/字体变化后重新测量，远端尺寸去重并串行同步，卸载取消。
- 当前 xterm 5.3 在根元素 `mousedown` 无条件 `preventDefault`；仅在原生 viewport 上阻止事件冒泡，不阻止默认拖动，不干扰 `.xterm-screen` 文本选择。
- 关闭全部入口按用户后续要求移入连接标签右键菜单，文案为“关闭全部”，移除右上角按钮并保留原确认链。
- 服务搜索框与进程、Docker 页签统一使用 `sm` 尺寸和 180px 宽度。
- 服务列表始终拉取全部再本地组合筛选，避免刷新后只剩某一状态。新增 owner IPC 调用 `systemctl --no-pager cat -- <unit>`，参数校验并 shell quote；只读弹窗复用 `UiCodeEditor`，显示超时/权限/不存在错误；序号隔离连接切换与晚到结果。
