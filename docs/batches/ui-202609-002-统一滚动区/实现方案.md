# 统一滚动区实现方案

起始 HEAD：`a370f39`。已有明确授权，按以下方案持续实施。

## 设计与接入

- `UiScrollArea` 复用 Reka Primitive，`as-child` 模式保留现有实际滚动元素及引用；`axis` 取 vertical、horizontal、both，分别设置对应原生 overflow 规则。
- `managed` 模式只提供主题和公共标记，不改变外部库控制的 overflow；xterm 与 CodeMirror 保留原生视口、尺寸计算与滚动同步。
- 统一 CSS 放在公共 UI 层，由全局样式导入。纵向宽度、横向高度一致，滑块透明边框留出呼吸空间，默认低对比、悬停和拖动逐步提亮；应用暗色与强制暗色使用同一组 tokens。
- 删除全局旧样式、编辑器独立滚动条样式和 SSH 局部补丁，避免多套样式互相覆盖。原生文本框及第三方生成的滚动元素也走同一套基础规则。
- 用模板 AST 迁移可滚动元素，循环 key 和条件分支移至组件外层，保留内部节点、事件和引用；增加公共 API 展示、源码守卫与关键行为回归代码。

代码已完成：50 个现有 Vue 文件中的 58 个滚动容器已迁移，组件实验室补充纵向、横向及固定暗色双向示例。全仓滚动条视觉规则集中在公共 CSS，终端与编辑器通过 managed 模式接入。
