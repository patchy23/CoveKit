## 3. 覆盖矩阵（决策书 §2.3 逐条）

| §2.3 必需场景 | 用例 |
| ---- | ---- |
| 两连接 / 两 tab 结果归属 | 两个连接的两个页签并发执行，结果各自落在发起页签（乱序完成） |
| 旧响应晚到 | 切走页签后旧响应晚到，不写入当前页签；失败的查询只写发起页签并在该页签可见错误 |
| 取消后重试 | 取消只作用于当前页签的请求（同连接另一页签仍完成）；取消后重试：新结果写回同一页签且不停留在 running |
| 关闭一个 tab 不影响另一个 | 关页签不影响另一页签状态与页签名；删连接只关该连接的页签并失效其缓存；最后一个连接禁删；删除失败保留连接与页签 |
| 元数据缓存按连接与 schema 隔离及失效 | 同名 schema 不串读；断开连接只失效该连接缓存；库/schema 下拉跟随当前页签连接、系统库开关只影响本连接；拉取失败经提示条可见且可重试 |
| 历史与收藏成功 / 失败 | 成功失败都写历史并刷新；历史写入失败不影响结果呈现、列表拉取失败可见；收藏成功更名并复位 dirty；无内容保存被拦下；保存失败向上抛出且不留假已保存态；删除收藏与清空历史后刷新 |
| 保存期间切 tab 的归属 | 保存过程中切页签，保存结果仍写回发起页签且不抢焦点；已保存页签重命名同步到库 |

附加（门面反馈可见性）：提示条 4 秒自动清除；树上 DDL 成功给 toast、失败只提示不 toast；
表删除/重命名后关闭指向旧表的页签；数据页签按自身状态加载分页，切页签不影响已加载结果。

## 4. 行为网暴露的缺陷：结果回填按「当前活动页签」、取消按「连接」一刀切

其余 23 例（页签/连接连带、缓存隔离、历史收藏、保存期间切页签、门面提示）修复前即通过，
即缺陷范围**只在执行结果的归属与取消身份**，不是整个工作区状态模型失效。

### 4.2 根因（代码实测，非推测）

1. `workspace/useQueryWorkspace.ts` 的 `runQuery` / `cancelQuery` 在 `await` 之后用
   `patchQueryState()` 回填结果，而该函数写的是**调用时刻的活动页签**（`activeTabId`）。
   用户在执行期间切走页签，结果就落到别人头上；晚到的旧响应还会覆盖新页签的状态。
2. 后端 `dbc_cancel(state, conn_id)` 的取消句柄注册表以**连接 id** 为键（`DbCancelState`），
   同一连接只能登记一个句柄：同连接两个页签并发执行时后登记的覆盖先登记的，取消也无法点对点命中。
   决策书 §2.3 要求的「同连接多 tab 隔离」在此粒度下不可能满足。

### 4.3 修法：最小请求身份（前端 + 后端契约同步）

- 前端每次执行生成 `requestId`（`requestId.ts`：`nextRequestId(scope)`，形如 `q3#7`），
  随 `dbc_execute` 上报，写在页签级的在途表 `inFlight: Map<tabId, requestId>` 里。
- 回填只认自己：`settleRequest(tabId, requestId)` 仍匹配时才写**发起页签自己的状态对象**
  （`patchTabState(state, …)`，新增；`patchQueryState` 仍是组件写活动页签的公开入口）。
  已取消或被新请求取代的迟到成功/失败一律作废，页签状态停在「已取消」，不被改写成错误。
- 取消按请求身份：`dbc_cancel(requestId)` 命中本次页签的请求；没有在途请求时不打扰后端
  （「取消与预期缺失不报错」）。取消 IPC 失败走提示条，不假装已取消。
- 后端 `catalog.rs`：`dbc_execute` 增加 `requestId`（空值直接拒绝），取消句柄按请求身份登记/注销；
  `dbc_cancel` 改为 `requestId`。顺手把 Redis 会话分支并入统一 match，成功/失败/取消都走同一条注销路径。
- 契约改动同步在 `contracts.ts`（`dbc_execute.requestId` / `dbc_cancel.requestId`）、`ipc.ts` 与
  两个调用点（查询工作区、目录 DDL）；命令名与归属者未变，`manifest_contract_tests.rs` 的已发布命令表无需更新。

### 4.4 影响面与回退

- 影响面：数据库插件的查询执行与取消；命令签名向后不兼容（同版本前后端一起发布，无跨版本混用）。
- 回退：本次修复与测试分为独立提交（见 §7），`git revert` 任一提交即可取回；结构拆分本身未回退。
