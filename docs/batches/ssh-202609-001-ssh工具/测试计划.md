## 1. 测试范围

| 模块 | 对应需求 | 优先级 | 契约命令 |
|------|---------|--------|---------|
| 服务器连接管理 | P0-1 | P0 必测 | ssh_connect / ssh_disconnect / ssh_reconnect / ssh_connections |
| SSH 终端 | P0-2 | P0 必测 | ssh_terminal_open/write/resize/close/list + `ssh://terminal-data` 事件 |
| 文件管理（查看/上传/下载） | P0-3 | P0 必测 | ssh_file_list/upload/download/delete/rename + `ssh://transfer-progress` 事件 |
| 凭证管理（密码/密钥） | P0-4 | P0 必测 | ssh_credential_save/get/delete |
| 远程编辑 | P1-5 | P1 应测 | ssh_edit_open/save |
| 资源监控 | P1-6 | P1 应测 | ssh_monitor_get |
| 服务管理 | P1-7 | P1 应测 | ssh_service_list/action/logs |
| 进程管理 | P1-8 | P1 应测 | ssh_process_list/kill |
| Docker 容器 | P2-9 | P2 可选 | ssh_docker_list/action/logs/exec |
| 终端分屏 / 快速命令 / 主题自定义 | P2-10/11/12 | 不实现（后续迭代） | 边界回归：确认无越界实现 |
| 非功能（性能/安全/稳定性/可维护性） | §6 | P0-P1 | 契约一致性 + Rust 单测 + 联调 |

**不测试（边界）**：SFTP 拖拽可视化、网站/数据库/计划任务/防火墙管理、i18n、服务器分组树、终端录制/回放、SSH 隧道/端口转发——按需求 §4 明确不做，仅做"无越界实现"回归。

## 2. 测试环境

### 2.1 当前环境评估（2026-08-09，Windows 10 + git-bash）

| 项 | 状态 | 说明 |
|----|------|------|
| pnpm / vitest | ✅ 可用 | `export PATH="/c/Users/patchy/AppData/Roaming/npm:$PATH"` 后 `pnpm test` |
| 前端 UI（mock 模式） | ✅ 可测 | `pnpm dev` 起 Vite，纯前端演示数据 |
| ssh 客户端 | ✅ 有 | OpenSSH_10.0p2（仅客户端，无法自测服务端） |
| 本地 sshd（:22 监听） | ❌ 无 | 本机无 SSH 服务端 |
| docker | ❌ 无 | 无法本地起 sshd 容器 |
| GitHub 远端 | ❌ 不可达 | fetch 被重置（无法拉取 feature/ssh-backend 分支） |

**结论**：阶段 A（前端单测 + UI 走查）可在本机完成；阶段 B 的联调验收（真实连接/终端/文件）需要外部 SSH 服务器（公司服务器 / 云主机 / 其他可连主机），Rust 侧命令与契约一致性核对不依赖网络（读代码即可），cargo test 在本机可跑（待后端分支可用后执行）。

### 2.2 联调候选服务器

- 用户提供的外部服务器（生产/测试机均可，需 root 或具备 systemctl/journalctl/docker 权限的账号）
- 注意：监控/服务/进程/Docker 模块需要 Linux 环境；Windows OpenSSH 服务器无法覆盖这些模块

## 3. 测试策略

| 层级 | 手段 | 时机 |
|------|------|------|
| 纯函数单测 | vitest（useSsh.test.ts） | 阶段 A，随时可跑 |
| UI 走查 | 代码走查 + dev server 浏览器核对（布局/交互/空态/深色模式/反馈） | 阶段 A |
| 契约一致性核对 | 读 feature/ssh-backend 代码，与 contracts.ts 逐命令比对（字段 camelCase、事件名、错误结构） | 阶段 B |
| Rust 单测 | cargo test（后端可编译后） | 阶段 B |
| 联调验收 | 真实 SSH 服务器手工用例（联调验收清单） | 阶段 B |

## 4. 用例分级与编号规则

- **P0 必测**：连接管理 / 终端 / 文件管理 / 凭证管理 + 状态机核心流转
- **P1 应测**：远程编辑 / 监控 / 服务 / 进程 + 非功能关键项
- **P2 可选**：Docker / 锦上添花项（时间不足可跳过并标注）

编号规则：`SSH-<模块>-<序号>`，模块前缀：

| 前缀 | 模块 | 前缀 | 模块 |
|------|------|------|------|
| C | 连接管理 | S | 服务管理 |
| T | 终端 | P | 进程管理 |
| F | 文件管理 | D | Docker |
| CR | 凭证管理 | U | 通用 UI / 状态机 / 布局 |
| E | 远程编辑 | X | 边界回归 |
| M | 监控 | N | 非功能 |

用例状态：`待执行`（依赖后端） / `通过`（前端已验证） / `失败`（走查发现问题） / `不适用`。

## 6. 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 无真实 SSH 服务器 | 联调用例无法执行 | 外部服务器就绪后补跑；Rust 单测先行覆盖纯逻辑 |
| 后端分支不可达 | 阶段 B 契约核对延后 | 网络恢复 / 分支推送后执行；契约核对为纯读操作 |
| mock 数据与真实数据形态差异 | 前端验证失真 | 走查清单逐项标注"待后端接入项"，联调时回归 |
| 深色模式需人工目测 | 自动化难以断言 | 走查清单列出目测项，截图留证 |
