# Agent开发体系收敛任务书

> 批次：docs-202609-002-agent开发体系收敛；起始HEAD：e2f514e。
> 用户在八项具体评审后授权“你来负责帮我优化”，本批实施该评审范围。进度只见进度台账。

## 范围

1. 用户裁决进入必读路径，完整台账按批次读取；入口与UI任务读取减重。
2. 台账唯一维护进度，批次文档保存证据，README只导航；消除自引用提交规则。
3. 修复预算与台账假绿，新增独立Markdown链接检查、负例测试和CI文档门禁。
4. 收敛旧手册/模板的过期规则、工具绑定和危险进程清理建议。
5. 按风险明确S1–S4、三轮无进展诊断、开发自测与独立验收；保留大任务两份文档确认要求。
6. 以按钮文案、IPC修复、SSH需求、批次接手四条读取路径验收。

## 非范围

不改业务代码、Rust检查语义、用户已裁决的测试豁免、技术栈或平台承诺；不引入外部harness平台。不全量改写历史批次正文，不将历史未实测改成已通过。

## 验收

- 超预算新文档、非法状态、已完成无证据、无效提交、缺失链接均非零退出，负例可自动重复运行。
- CI独立文档任务包含负例、预算、台账和Markdown链接检查，不编译Rust；Git历史可用。
- 默认必读内容含TODO裁决且不超过15,000字符；UI路径按所需章节加载，报告实际字符数。
- 规则无多个进度权威、无同提交自填hash要求、无按进程名强杀用户应用建议。
- 实际仓库文档检查通过；记录覆盖边界，不宣称证明文档语义正确。
