# 开发约束与反馈收敛任务书

> 状态：实现与本地验收完成，远端 CI 未运行。授权：2026-09-16 当前会话用户批准落地方案并要求“帮我调整”。

## 目标与范围

让咨询保持只读、小修改动与验证适度、大任务先任务书和方案并按验收交付。调整 AGENTS、工作流、模板、活动任务入口、历史身份、文档检查器与 CI 分流。不改变产品功能、既有范围裁决、本地不跑 Cargo 的裁决，不整理 Git 历史。

## 验收

- 咨询默认零写入、零提交；小修没有强制批次、台账或回填提交。
- 大任务两份材料保留；已批准步骤持续执行，实质偏离需确认。
- TODO 是活动入口，方案承载接续状态；原台账冻结，既有裁决有可达落点。
- 历史材料不产生执行义务；临时材料默认不入库。
- 文档检查不扫描未跟踪草稿；普通文档大小仅提醒；删除台账格式与 hash 门禁。
- 纯文档变更不触发产品构建；未知工程路径按完整检查处理；失败不能被跳过掩盖。
- 检查器行为测试与相关静态检查通过；未执行的远端 CI 明确说明。
