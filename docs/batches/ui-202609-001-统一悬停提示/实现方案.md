# 统一悬停提示实现方案

起始 HEAD：`5ce339e`。用户已明确授权全仓替换，无需再次确认同一范围。

## 实施

1. 使用 Vue 模板 AST 区分原生属性、公共控件提示与标题用途，结合文本扫描检查动态 DOM 和自定义悬停。
2. 公共组件内直接引用 `UiTooltip`；业务从 `@/core/ui` 引入。保持 as-child 不增加布局元素；条件与循环移到提示包装层，循环 key 和作用域保持一致。
3. 表格单元格、复选框、开关和列表行的现有提示均接入公共组件。普通文本保留完整提示；图标操作保留或补齐无障碍名称。
4. 增加源码守卫，禁止原生节点 `title`，只允许明确的公共提示入口或非悬停标题组件；补元素引用、条件/循环和表格结构回归代码。

## 验证与状态

用户实测后确认交互调整：提示默认位于下方，空间不足自动翻转；停留 400ms 才出现，离开立即关闭；文字不可选中、提示层强制鼠标穿透。共享提示归属在进入新目标时失效旧提示，旧目标延迟回调不能重新打开。关闭 Reka 的可悬停内容和跳过延迟行为，保留键盘聚焦、Esc 和原有事件。增加连续经过最小化、最大化、关闭按钮的互斥及迟到回调回归代码。

代码替换完成。全仓模板扫描已无原生节点或未接入组件的 `title`；剩余属性均属于已接入公共提示的控件或真正的标题。动态 DOM 与鼠标事件源码扫描未发现另一个应用自有文字提示实现。编辑器补全/诊断浮层保留 CodeMirror 生命周期及已有设计 token 主题。

39 个迁移文件经模板 AST 对照，去除提示包装及无障碍名称补充后，原元素结构、属性与事件未发生变化。复选框和开关把提示挂在实际可聚焦的控件上；`UiTooltip` 保持空/非空内容切换时的节点身份，`UiButton` 转发真实元素引用，嵌套提示隔离只作用于无按键的悬停，拖拽事件继续传播。
