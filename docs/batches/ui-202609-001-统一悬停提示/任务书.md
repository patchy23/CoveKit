# 统一悬停提示任务书

用户已授权检查并替换所有悬停提示。基于已落地的 `UiTooltip`，统一应用自有文字提示的外观、延迟、视口避让和键盘行为。

- 检查 `src` 的 Vue 模板、动态 DOM 属性与自定义悬停实现，替换原生 `title` 提示。
- 保留弹窗、面板、通知和文件选择器的标题语义；编辑器补全、诊断等有独立交互契约的浮层继续使用公共编辑器基座和主题。
- 保持布局、表格结构、列表键、条件分支、元素引用、拖拽与事件行为；无文字的操作保留无障碍名称。
- 按用户实测反馈统一为下方优先、400ms 延迟、离开立即关闭、全局最多一个、鼠标穿透且不可复制的轻量提示。
- 新增源码守卫和关键交互测试代码。验证遵循现有本地与 CI 分工，未执行不写通过。

实现与状态见[实现方案](实现方案.md)。
