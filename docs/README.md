# patchyBox 文档地图

桌面工具箱项目 · 设计方向：**② 明净浅色 · 内容优先**

> **本文是文档的唯一索引入口。** 找文档先看这里；**进度看 [`进度台账.md`](进度台账.md)**，待办与裁决看 `TODO.md`。
> **新会话别急着通读本文**——先看下面的「最小必读集」，按任务按需读。
> 文档分三层：**常青规范**（现在是什么样）、**批次文档**（某次开发的过程产物）、**插件文档**（单个工具自己的定义）。

> **新会话 / 新 AI 接手先读**：`../AGENTS.md`（红线速查）→ `standards/10-AI开发工作流.md`（怎么开工）→ 本文（有什么文档）。

## 最小必读集

**新会话开工只读这四份**（合计约 2.3 万字符）；其余文档**按任务按需读，禁止全量扫 `docs/`**——仓库现有 75 份文档约 50 万字符，全读会直接吃掉上下文。

1. `../AGENTS.md` —— 常青红线（会话自动注入，一般无需手动再读）
2. `进度台账.md` —— 每份任务书执行到哪、哪些还没开工、证据是哪个提交
3. `standards/10-AI开发工作流.md` —— 怎么开工：定档、确认门禁、验证命令
4. `README.md` —— 本文：有哪些文档、放哪、叫什么

## 命名规范

| 层 | 位置 | 命名 |
| --- | --- | --- |
| 常青规范 | `standards/` | `<两位序号>-<中文标题>.md`，序号只在 `standards/` 内递增 |
| 跨批次决策 | `adr/` | `ADR-<四位序号>-<中文标题>.md`，一经采纳不再修改正文，只能被新 ADR 取代 |
| 插件常青文档 | `plugins/<id>/` | 中文标题（`需求.md` / `设计.md` / `界面设计.md` / `竞品分析.md`） |
| 批次文档 | `batches/<批次号>/` | 目录名 = `<领域>-<年月>-<编号>-<中文简述>`，如 `ssh-202609-001-ssh工具`；目录内文件名按角色（任务书 / 执行计划 / 决策书 / 补证据记录 / 测试计划） |
| 目录索引 | 任意目录 | 统一 `README.md` |

**批次号规则**：`<领域小写英文>-<YYYYMM>-<三位序号>-<中文简述（10 字内）>`。
领域取模块或能力名（`ssh` / `frp` / `db` / `arch` / `rel` / `sync` / `editor` / `storage`），序号在同一领域同一月份内递增。
**一个批次 = 一次开发**：开工时先认领批次（新建或并入已有批次），批次内的进度只写该批次的 `README.md`，跨批次关联靠批次号识别。

描述「这个工具是什么」，随插件演进更新，不随某次开发完结而归档。

```

├── ssh/       需求.md · 设计.md · 界面设计.md · 竞品分析.md
│              终端配色与高亮.md · 双栏传输UI对照.md

└── vault/     设计.md · 落地笔记.md
```
