# patchyBox 文档地图

桌面工具箱项目 · 设计方向：**② 明净浅色 · 内容优先**

> **本文是文档的唯一索引入口。** 找文档先看这里；进行中的工作进度看 `TODO.md`。
> 文档分三层：**常青规范**（现在是什么样）、**批次文档**（某次开发的过程产物）、**插件文档**（单个工具自己的定义）。

## 命名规范

| 层 | 位置 | 命名 |
| --- | --- | --- |
| 常青规范 | `standards/` | `<两位序号>-<中文标题>.md`，序号只在 `standards/` 内递增 |
| 跨批次决策 | `adr/` | `ADR-<四位序号>-<中文标题>.md`，一经采纳不再修改正文，只能被新 ADR 取代 |
| 插件常青文档 | `plugins/<id>/` | 中文标题（`需求.md` / `设计.md` / `界面设计.md` / `竞品分析.md`） |
| 批次文档 | `batches/<批次号>/` | 目录名 = `<领域>-<年月>-<编号>-<中文简述>`，如 `ssh-202609-001-ssh工具`；目录内文件名按角色（任务书 / 执行计划 / 决策书 / 补证据记录 / 测试计划） |
| 目录索引 | 任意目录 | 统一 `README.md` |

**批次号规则**：`<领域小写英文>-<YYYYMM>-<三位序号>-<中文简述（10 字内）>`。
领域取模块或能力名（`ssh` / `frp` / `db` / `arch` / `rel` / `sync` / `editor` / `storage`），序号在同一领域同一月份内递增。
**一个批次 = 一次开发**：开工时先认领批次（新建或并入已有批次），批次内的进度只写该批次的 `README.md`，跨批次关联靠批次号识别。
