- 配置域 → 连接域：`closeConnectionsOf(profileId)`、`forgetActiveProfile(profileId)`

- 生命周期域 → 连接域/主机密钥域：事件回调与 `onDispose`（取消积压确认 + 断开全部会话）

`connectionWorkspaces` 只在连接域写；配置域不持有连接，生命周期域不持有状态。

超线理由是**单一可写状态 + 单一修改原因**：全部代码围绕 `connectionWorkspaces` 这一份状态（建/关/重连/事件映射/活跃刷新），
