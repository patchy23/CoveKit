## 任务目标
为 SSH 远程管理工具完成：① GitHub/竞品调研与功能分析 → ② UI 功能设计 → ③ IPC 契约设计（可冻结的完整草案）。
**本阶段只做分析与设计，不写任何实现代码（不实现命令逻辑、不写 Vue 组件实现）。**

## 功能需求（用户原话，8 项）
1. 远程命令行（SSH 终端：交互式 shell，支持窗口大小调整、Ctrl+C 等控制字符）
2. 文件管理：查看目录、上传文件、下载文件
3. 服务器资源监控（CPU / 内存 / 磁盘 / 网络，实时刷新）
4. 服务管理（systemd 服务列表 / 启停 / 查看状态）
5. 进程管理（进程列表 / 详情 / 结束进程）
6. Docker 容器管理（容器列表 / 启停 / 日志 / 进入容器终端）
7. 远程编辑文件（打开远程文件 → 本地编辑 → 保存回写）
8. 服务器登录凭证管理（多服务器管理、用户名/密码或 SSH 密钥、加密存储）

## 调研要求（第 1 步，先做这个）

- 每个项目记录：star 数、核心功能、UI 形态、技术栈、仓库地址
- 分析每个工具对上述 8 项功能的支持方式与亮点交互
- 产出《竞品分析》：功能矩阵表格（行 = 8 项功能，列 = 各竞品，单元格 = 支持情况 + 亮点） + 可借鉴交互清单（注明来源项目）

## 设计约束与规范
- 命令命名 snake_case，按功能分组：连接 / 终端 / 文件 / 监控 / 服务 / 进程 / docker / 凭证；每条命令附中文说明（ipc_registry 入库格式）
- 连接会话模型参考 http-ws 的 WsState 模式：`id → 会话句柄 + 后台任务`；凭证**禁止明文落盘**
- 契约总量建议 20-30 条命令（分批后第 1 批 ≥12 条）
- 全部文档与注释中文；代码标识符英文
- UI 参考 Termius / 1Panel 的"服务器列表 + 页签工作区"形态，但必须遵循 patchyBox 的明净浅色 tokens（不得照搬其深色控制台风格）
