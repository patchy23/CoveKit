## 任务目标
实现 SSH 插件后端全部 29 条命令 + 3 个事件推送，覆盖 8 大功能：连接会话、终端、文件管理（SFTP）、凭证（stronghold）、远程编辑、资源监控、服务管理、进程管理、Docker 管理。

## 技术选型（已定，不要更换）
- **SSH 客户端**：`russh` crate（异步，tokio 原生，支持多通道/PTY/SFTP）
- **凭证加密**：`tauri-plugin-stronghold`（AGENTS.md 既定决策；需在 Cargo.toml 加依赖 + lib.rs 装配处注册插件——见下方"装配"说明）
- **SFTP**：russh-sftp 或 russh 通道内实现（按 russh 生态实际情况选）
- **终端数据**：PTY 通道（russh Channel::RequestPty）+ resize 请求；输出经 `app.emit("ssh://terminal-data", ...)` 推送
- **会话模型**：参考 http_ws 的 WsState 模式——`SshState(Mutex<HashMap<String, SshSessionHandle>>)`，id → 连接句柄（含 russh session + 通道 + 各功能状态）

## 命令契约要点（全部按 contracts.ts）
- 命令名 snake_case 与 contracts.ts 一致；`#[tauri::command(rename_all = "camelCase")]` 处理字段
- 错误统一 `Err(String)` 或 `{ ok: false, error: Some }` 结构，禁止 panic
- 命令全部在 `register()` 里调 `crate::framework::ipc_registry::register(&[...])` 入库（每条附中文说明）
- 事件名严格用契约的 `ssh://terminal-data` / `ssh://transfer-progress` / `ssh://connection-status`，负载与契约类型对应
- 文件上传/下载：异步后台任务 + 进度事件（每 ≥1% 或每 256KB emit 一次），命令立即返回 transferId 相关结构
