# SSH 文件管理页 · 架构模式与路径坑

> **何时读**：改 SFTP 双栏、本地路径与元数据展示时。
> **本文讲什么**：文件管理器型页面的架构模式，以及本地路径与元数据展示的实测坑。

---

## SSH 文件模块·本地路径与元数据展示坑（2026-09-08 实测）

- **Windows 路径规范化必须下沉后端，前端禁做字符串手术**（用户纠偏「不要自己研究，先看开源实现」）：`ssh_local_list` 入参为空/`/`/`\` 时返回驱动器列表——「此电脑」是 Shell 命名空间式虚拟层（WinSCP/FileZilla 本地侧同款），由文件系统抽象自身处理。前端逐层打补丁曾连环踩坑：① `C:` 裸盘符是「该盘当前目录」而非根，必须补成 `C:\`；② `read_dir('/')` 在 Windows 静默解析到当前盘根（表现为「切不了盘」）；③ 驱动器视图哨兵 `''` 是假值，`:disabled="!parentPath"` 和 `if (parentPath)` 都误判禁用——合法上级用 `!== null` 精确比较。规范化纯函数 `normalize_local_path` + 单测在 sftp/browse.rs。
- **SFTP 元数据展示**：权限位转 rwx 字符串（`drwxr-xr-x`，`format_permissions` 纯函数带单测，在 sftp/util.rs）——八进制 `40755` 用户看不懂；owner/group 两级回退 `user(名字) → uid/gid(数字) → "-"`——russh-sftp 的 `FileAttributes.user` 是 longname 解析名（多数服务器不给），`uid` 才是线协议标配。
- **UiTable 长文本截断：auto 布局 + 弹性列 `max-w-0` + 内容 `block truncate`**（完整值挂 title）；**勿用 table-fixed**——它按列声明宽度分配，无固定宽度的名称列在窄容器里会被分到 0 宽整列消失（2026-09-08 FileBrowser 实测：table-fixed 下默认窗口文件名全没，回退 auto + max-w-0 后正常截断）。大小/时间等数据列补 `whitespace-nowrap` 防换行。
- **错误信息带操作对象上下文**：`读取目录失败: {e}` → `读取目录失败 [{path}]: {e}`——os error 123（尾点/尾空格目录名触发 legacy API 拒绝）这类只有看到具体路径才能定位。

## 文件管理器型页面架构模式（2026-09-09 SFTP 双栏增强定稿）

双栏/多选/批量类页面（SFTP 双栏为首个实例，数据库等后续类似页可复用）的装配分解：

- **多选**：`useFileSelection(orderedPaths)`（单选/Ctrl 切换/Shift 锚点范围选/空白清空；Shift 范围是 `shiftRange` 纯函数带单测）；选择集永远重赋值新 Set 触发响应式；单选操作经 `computed({get:恰好一项, set:清空})` shim 兼容旧 Ref 契约
- **右键菜单按场景矩阵出项**（`useFileContextMenu` 远程 / `useLocalContextMenu` 本地；单选文件/单选目录/多选/空白四态 + 全部带刷新）：**列表占满无空白处时，空白场景的入口必须在单选菜单备份**——「新建文件/新建目录」等空白专属项以分隔线分组追加到单选菜单尾部（用户报「文件多时根本没有空白地方可右键」），多选菜单保持批量语义不掺入；右键未选中项先 `selectOnly` 对齐（业界惯例），多选集合内右键保持多选；危险项可见性走 `sshPolicy.ts` 前端镜像（**权威判定必须在后端**，前端只藏菜单项，防 IPC 直调）
- **双栏中列传输按钮定稿（2026-09-10 四轮后）= 最简裸箭头**：两个按钮 `arrow-left`（上传到远端）/ `arrow-right`（下载到本地），中列 `w-[42px]`，**没有文字标签、没有配色**，完整语义只写在悬停 `title` 里；方向始终**指向目标栏**（服务器在左、本地在右）。走过的弯路别重走：文本「→」、单 lucide upload 图标、「抵线箭头（`arrow-left-to-line` / `arrow-right-to-line`）+ 「上传 / 下载」文字标签 + 上传侧 `text-tertiary-strong` 配色 + `w-[58px]`」三版都被用户否或看过实机后撤回——**最后一版还是按同类产品调研推荐的，用户先点头、看到实物才要求改回**：这类栏内符号默认给最简形态 + `title` 说明，装饰（标签 / 配色 / 更大图标）要在用户明确要求时再加；撤回时把只服务于它的 UiIcon 注册项一并删掉，不留死注册项。中列下载按钮**多选时必须走批量链路**（`emit('batchDownloadSelected', 选中集)`）：只喂单选 shim（`selectedFile` 恰好一项才非空）会在多选时误报「请先选择文件」
- **同屏多栏的状态栏必须定高对齐**：两侧状态栏都写 `h-[36px] shrink-0 items-center`，不要各自 `py-*` 撑高——带 36px 图标按钮（书签/传输）的那侧会被撑高，比纯文本侧高一截（用户报「左右侧底栏高度不一样」）
- **批量操作两段式**：`useFileBatchOps` 的 `request*`（设 BatchConfirm 弹窗载荷：标题/前 5 项预览/危险档）→ UiConfirmDialog → `confirm*` 执行，单项失败不中断其余、结束汇总 toast
- **文件工具栏动作槽**：FileBrowser 的 `status-actions` 插槽位于路径栏下方工具栏，注入目录书签、传输任务和编辑器入口；底部状态栏仅展示当前路径和选择状态。
- **跨栏传输目标**：下载直落本地栏当前目录，不弹保存框；目录递归下载，批量操作先确认。同名冲突保留失败记录，在传输面板明确确认后重新传输并覆盖。上传维持同名覆盖语义。
- **规模评审信号下的拆法**（约 300 物理行触发职责审查，不是自动失败条件；超线在提交说明写职责与拆分依据，禁止靠复制实现或挪进巨型 use 文件压行）：装配层（Tab）只留组合，导航（useRemoteDirectory）/菜单接线（useFileManagerMenus）/双栏布局（FileManagerPanes）/浮层群（FileManagerOverlays）/状态栏动作（FileStatusActions）各成组件；**defineExpose 的 ref 在父级组件实例上自动解包**（`localBrowser.value?.files` 直接是数组，再写 `.value` 就是 TS2339，本批踩过）；**压行按「删注释/空行→压 watch 块→合并表达式」顺序**，勿依赖多语句合并压行（prettier 会重新拆成多行，白压）；注释保持独立行，塞进函数签名/表达式中间 vue-tsc 直接语法错；**菜单项数变化时同步上调 openMenu 的坐标夹取估算**（`window.innerHeight - N * 36` 的 N，项数=估算上限才夹得准）
- **vite 模板编译错误会在 dev 弹全屏 error overlay**（HMR 不白屏但页面被遮罩盖住）——门禁跑 vue-tsc 之外，dev 实测第一眼先看有没有红顶遮罩



## 书签、传输与远程编辑工作区

- 目录书签由文件工具栏打开独立 UiPopover，按服务器配置共享；支持搜索、收藏、重命名、重排和移除。重排后端事务校验整组归属，避免部分保存。
- 传输使用 UiBottomPanel。任务在请求发出时即显示准备状态，目录以一次任务汇总；按方向、路径、状态展示进度和速度，可搜索、筛选、取消、定位及重新传输。最近 200 条终态保留，切换功能页不会清理任务。重试为全量传输，确认后覆盖同名文件，不提供断点续传。
- 文件编辑使用非模态工作区，左侧 UiTree 按目录展开加载，右侧每个文件拥有独立 UiCodeEditor；页签切换与收起保留编辑实例。目录可收起，文件可分别保存或全部保存。关闭未保存文件需选择保存、放弃或返回。
- 保存以打开时的远端修改时间检查冲突，冲突先展示差异，由用户决定覆盖或重新读取。保存期间的新输入仍标记为未保存；失败、断线不会清空草稿。
- 文件页首次访问才挂载，断线后保留已打开的编辑器；连接关闭和工具/应用关闭均提示未保存内容。草稿仅在内存中保留，不自动落盘。
