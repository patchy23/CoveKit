# SSH 文件管理页架构

本文说明文件页面的状态归属、路径与资源约束。用户可见行为以 [SSH 文件工作区](../../standards/07a-需求-SSH远程管理.md#文件工作区)为准。

## 状态与装配

- 页面装配负责组合目录导航、列表选择、菜单、传输与编辑器，不重复实现各自状态机。
- 多选状态独立于目录行对象，使用路径作为稳定标识；目录切换或刷新时校验选择仍然有效。
- 异步目录请求绑定连接与请求代次，迟到结果不得覆盖新目录或已关闭的工作区。
- 右键未选中项先对齐选择；在已有多选集合内右键保留集合。单选菜单保留新建入口，列表占满时仍可操作；批量菜单保持批量语义。
- 危险操作的前端菜单可见性只做交互提示，后端必须独立校验。

## 本地路径与元数据

Windows 路径规范化由后端处理，前端不拼接盘符语义。空路径和根视图由本地文件系统适配返回驱动器列表；`C:` 与 `C:\` 不等价。合法上级路径使用 `!== null` 判断，不能把空字符串驱动器视图当成无上级。

远端权限显示为 rwx 文本，属主和组名缺失时回退到 uid/gid，再回退到缺省标记。长名称保留完整提示并截断显示，大小与时间列避免换行；不要用会把弹性名称列挤为零宽的固定表格布局。

错误应包含操作类型与可定位的路径上下文；不记录文件正文、密码或私钥。

## 传输调度

下载对话框选择目标与跨栏拖拽直接使用本地栏目录是不同入口。目标在执行前完整入队，每连接最多两项传输，同目标及父子路径串行；目录以一个任务汇总。

取消覆盖等待、准备和运行阶段，后台确认结束前不伪造终态。文件下载先写临时文件再替换，失败或取消保留原文件；目录合并不删除额外文件，文件与目录类型冲突明确报错。重试是重新传输，不承诺断点续传。

传输状态归连接所有，切换功能或关闭传输浮层不停止任务。关闭连接与应用退出通过统一资源协调入口执行。

## 远程编辑与窗口交接

编辑器归连接所有并挂载于 SSH 工具根层，目录树按需加载，每个文档保留独立草稿。正文只在内存中保留，不自动落盘。保存期间的新输入仍为未保存状态，失败或断线不清空草稿。

保存检查远端修改时间；冲突先展示差异，再由用户决定覆盖或重新读取。关闭文档、连接或应用均检查未保存内容，提供保存、放弃和返回。

独立窗口复用现有会话，接管期间主窗口只保留同步草稿。移入或移回须确认接收后再释放原编辑器；文档、活动页签、目录和光标/滚动位置迁移，撤销历史不迁移。窗口关闭和连接断开不得绕过草稿保护。

## 验证重点

覆盖驱动器导航、目录切换迟到回包、多选菜单、传输取消、同目标串行、失败保留原文件、保存冲突、断线草稿保护和跨窗口交接。源码入口为 `src/plugins/ssh/files/` 与 `src-tauri/src/plugins/ssh/`；验证命令统一见 [验证矩阵](../../standards/20-验证矩阵.md)。
