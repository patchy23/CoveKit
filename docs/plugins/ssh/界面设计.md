# CoveKit SSH 工具 · UI 设计

> 版本：v1.0（2026-08-08）  
> 设计约束：明净浅色 · 内容优先（macOS 式侧栏 + 大卡片网格）；交互驱动色 tertiary #F0562C；深色模式用 `-dark` token 变体  
> 布局参考：Termius / 1Panel 的「服务器列表 + 页签工作区」，但遵循 CoveKit tokens

---

## 2. 8 模块交互设计

### 2.1 服务器列表（侧栏）

```
┌──────────────┐
│ 🔍 搜索服务器 │
├──────────────┤
│ ┌──────────┐ │
│ │+ 添加服务器│ │
│ └──────────┘ │
├──────────────┤
│ ● prod-01    │  ← 在线（success-strong #067647 圆点）
│   192.168.1.1│
│   [终端][文件]│
├──────────────┤
│ ○ test-01    │  ← 离线（灰点）
│   10.0.0.5   │
├──────────────┤
│ ⟳ dev-01     │  ← 连接中（tertiary #F0562C 旋转图标）
│   172.16.0.3 │
└──────────────┘
```

**交互**：
- 单击：选中并连接（若未连接）/ 切换页签（若已连接）
- 右键/悬停操作按钮：编辑 / 删除 / 断开连接
- 添加服务器：弹窗表单（名称 / host / port / 用户名 / 认证方式）

### 2.2 SSH 终端（子页签）

```
┌─────────────────────────────────────┐
│ ● prod-01 · 终端          [× 关闭]  │
├─────────────────────────────────────┤
│ ┌─────────────────────────────────┐ │
│ │ $ whoami                        │ │
│ │ root                            │ │
│ │ $ ls -la /var/log/              │ │
│ │ total 128                       │ │
│ │ drwxr-xr-x  8 root root  4096   │ │
│ │ ...                             │ │
│ │ $ █                             │ │
│ └─────────────────────────────────┘ │
│ 状态栏：80×24  UTF-8  延迟 23ms     │
└─────────────────────────────────────┘
```

**交互**：
- 输入：键盘输入 → Tauri IPC → SSH channel 写入
- 输出：SSH channel 读取 → IPC 推送 → xterm.js 渲染
- resize：窗口拖动 → 获取行列数 → SSH `window-change` 请求
- 控制字符：Ctrl+C / Ctrl+D / Ctrl+Z 等直接透传
- 右键菜单：复制 / 粘贴 / 清空 / 重新连接

```
┌─────────────────────────────────────┐
│ ● prod-01 · 文件          [× 关闭]  │
```

**交互**：
- 双击目录：进入；双击文件：远程编辑（若文本类型）或下载
- 上传：Tauri 文件对话框选择本地文件 → SFTP 上传 → 进度 toast
- 下载：选中文件 → 保存对话框 → SFTP 下载 → 完成 toast
- 删除：选中 → 确认弹窗 → SFTP 删除 → 刷新列表
- 路径导航：面包屑 + 手动输入路径回车跳转

## 3. 连接状态机

```
        ┌─────────┐
        │  未连接  │ ◄────────────────────────────┐
        │ (灰色)   │                              │
        └────┬────┘                              │
             │ 点击「连接」                        │
             ▼                                   │
        ┌─────────┐     连接失败/超时            │
        │  连接中  │ ───────────────► ┌─────────┐ │
        │ (橙色)   │                  │  断开   │ │
        └────┬────┘                  │ (红色)   │ │
             │ 认证成功               └────┬────┘ │
             ▼                             │      │
        ┌─────────┐                        │      │
        │  已连接  │ ◄──────────────────────┘      │
        │ (绿色)   │      手动断开/网络断开          │
        └────┬────┘                              │
             │ 心跳检测失败 / 用户点击「重连」       │
             ▼                                   │
        ┌─────────┐                              │
        │  重连中  │ ─────────────────────────────┘
        │ (橙色)   │        重连成功 → 已连接
        └─────────┘
```

**状态说明**：
| 状态 | 颜色 | 触发条件 | UI 表现 |
|------|------|----------|---------|
| 未连接 | 灰 | 初始 / 断开完成 | 服务器列表灰点，主区空态 |
| 连接中 | 橙 | 用户点击连接 | 列表旋转图标，主区加载动画 |
| 已连接 | 绿 | 认证成功 | 列表绿点，子页签可用，状态栏显示延迟 |
| 断开 | 红 | 网络失败 / 手动断开 | 列表红点，toast 提示「连接已断开」 |
| 重连中 | 橙 | 自动 / 手动重连 | 列表旋转图标，终端显示「重连中...」 |

## 5. 设计 token 应用示例

| 场景 | token | 值 |
|------|-------|-----|
| 在线状态 | `success-strong` | #067647 |
| 连接中/重连中 | `tertiary` | #F0562C |
| 断开/错误 | `error` | #D92D20 |
| 终端背景（浅色） | `surface-primary` | #FFFFFF |
| 终端背景（深色） | `surface-primary-dark` | #1A1A1A |
| 页签激活 | `tertiary-strong` | #C2410C |
| 卡片背景 | `surface-secondary` | #F5F5F5 |
| 表格斑马纹 | `surface-tertiary` | #FAFAFA |
| 正文字号 | `text-body` | 14px |
| 标题字号 | `text-h2` | 18px |
| 终端字号 | `text-body-sm` | 13px（等宽字体） |
