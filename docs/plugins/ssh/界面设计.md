# SSH 界面设计

本文约定 SSH 工作区的界面组织。功能范围与关闭行为以 [SSH 需求](../../standards/07a-需求-SSH远程管理.md)为准；颜色、字号及间距使用 [DESIGN](../../../DESIGN.md)，不在本文复制 token 数值。

## 工作区布局

- 左侧服务器列表提供搜索、分组、连接配置与 CSV 导入导出；配置项与运行连接分开管理。
- 右侧按连接组织工作区，连接内切换终端、文件、监控、服务、进程、Docker、Compose 与隧道等功能。
- 功能区使用平直分栏与局部工具栏；加载、空态、失败及能力不支持状态均在对应区域表达。
- 状态、错误和危险操作不能仅用颜色区分；图标和文字提供明确语义，操作保留键盘入口。

## 终端与运维页面

终端使用 xterm.js，保持输入、调整尺寸、搜索与剪贴板行为一致。终端与应用快捷键按焦点划分，避免吞掉需要发送到远端的控制字符。

监控显示采样状态，断线或失败保留旧值并标记失效；服务、进程和容器列表在选定对象上执行操作。破坏性动作确认真实对象，操作后刷新状态。日志窗口关闭后停止对应后台任务。

## 文件与编辑器

远端列表与可收起的本地栏组成文件工作区。路径导航、选择、右键菜单与工具栏复用同一动作；传输箭头指向目标栏，通过提示说明上传或下载。

书签与传输入口在文件底部右侧，使用互斥点击浮层。关闭浮层不取消传输。下载对话框与跨栏拖拽的目标规则见 [文件工作区](../../standards/07a-需求-SSH远程管理.md#文件工作区)，不得混为同一种目标选择方式。

编辑器与日志窗口挂载在 SSH 工具根层，不受文件列表裁剪。功能页签右侧保留编辑器打开/恢复入口；最小化、切换功能和切换连接不丢失草稿。

文件编辑器可以移入独立系统窗口并移回主窗口。交接复用 SSH 会话，保留文档、活动页签、目录及光标/滚动位置；撤销历史不跨窗口迁移。接收确认前不销毁原工作区。连接、窗口和应用关闭统一检查未保存内容。

## 公共组件与实现入口

表单、树、表格、菜单和确认弹窗使用 `@/core/ui`；凭证选择使用 `@/core/vault`；代码编辑与差异查看使用 UiCodeEditor / UiCodeDiff。

前端位于 `src/plugins/ssh/`，按 profiles、terminal、files、monitor、docker、tunnels 等职责组织。组件签名查 [公共组件 API](../../standards/11a-公共组件API备忘.md)，文件状态与资源责任见 [文件管理页架构](文件管理页架构.md)。
