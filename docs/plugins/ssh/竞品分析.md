## 3. 竞品深度分析

### 3.1 Tabby（73.8k★）— 终端交互标杆
- **核心功能**：SSH/SFTP/Telnet/串口/RDP/VNC，多页签，分屏，主题，插件系统
- **UI 形态**：深色主题终端 + 顶部页签栏 + 左侧连接管理器
- **对 patchyBox 的借鉴**：
  - 页签工作区形态：一个服务器 = 一个页签，页签内再分终端/文件/监控子页签
  - 连接管理器：分组 + 搜索 + 快速连接输入框
  - 终端组件：基于 xterm.js，支持自定义字体/配色/滚动缓冲
- **技术栈参考**：Electron + xterm.js（前端渲染）+ ssh2（Node 后端）

### 3.2 1Panel（36.5k★）— 服务器管理功能最全
- **核心功能**：网站/数据库/Docker/文件/监控/防火墙/计划任务/备份，AI 代理集成
- **UI 形态**：Web 面板：左侧导航树 + 顶部标签 + 卡片式仪表盘 + 表格列表
- **对 patchyBox 的借鉴**：
  - 监控仪表盘：CPU/内存/磁盘/网络四卡片 + 实时折线图（ECharts）
  - 服务管理：systemd 服务列表（名称/状态/描述/操作按钮）
  - 进程管理：进程表格（PID/用户/CPU%/MEM%/命令）+ 搜索 + 结束进程
  - Docker 管理：容器列表（名称/镜像/状态/端口）+ 日志查看 + 进入终端
  - 文件管理：路径导航 + 文件列表 + 上传下载按钮
- **技术栈参考**：Go 后端 + Vue3 前端，WebSocket 实时推送监控数据

### 3.3 WindTerm（31.9k★）— 专业终端功能
- **核心功能**：SSH/SFTP/Shell/Telnet/Tmux/串口，多页签/分屏/会话管理器
- **UI 形态**：多页签 + 左侧会话树 + 底部状态栏（延迟/编码/行列数）
- **对 patchyBox 的借鉴**：
  - 会话状态栏：显示连接延迟、服务器信息、终端行列数
  - 分屏模式：单页签内左右/上下分屏，对比两台服务器
  - 快速命令：预定义常用命令，一键发送
- **技术栈参考**：C + Qt（原生性能），patchyBox 用 Tauri 2 可实现类似体验

### 3.4 electerm（14.7k★）— 文件管理双栏参考
- **核心功能**：终端 + SFTP/FTP 文件管理 + 书签 + 主题
- **UI 形态**：多页签 + 文件管理双栏（本地/远程）+ 终端底部面板
- **对 patchyBox 的借鉴**：
  - 文件管理双栏：左侧本地文件树，右侧远程文件树，拖拽上传下载
  - 终端与文件管理同页签：上方终端，下方文件管理，无需切换
- **技术栈参考**：Electron + xterm.js + ssh2

### 3.5 ttyd / webssh / webssh2 — Web 终端轻量方案
- **核心功能**：将终端通过 WebSocket 暴露到浏览器
- **对 patchyBox 的借鉴**：
  - 终端数据流模型：WebSocket 双向流 ↔ xterm.js 渲染
  - 轻量连接：无会话管理，直接输入 host/user/pass 连接
- **patchyBox 差异**：桌面端不需要 WebSocket 网关，直接 Tauri IPC 调用 Rust SSH 库，性能更好

### 3.6 FinalShell（闭源）— 国产一体化参照
- **核心功能**：SSH 终端 + 服务器监控 + 进程/服务/ docker 管理 + 远程编辑
- **UI 形态**：左侧服务器列表 + 右侧多页签（终端/监控/文件/进程/服务）
- **对 patchyBox 的借鉴**：
  - 服务器列表：树形分组 + 状态指示灯（在线/离线/连接中）
  - 单服务器多页签：终端/监控/文件/进程/服务/docker 作为子页签
  - 远程编辑：双击远程文件 → 下载到临时目录 → 本地编辑器打开 → 保存自动上传

## 5. 差异化定位（patchyBox 与竞品的区别）

| 维度 | patchyBox | 竞品 |
|------|-----------|------|
| 形态 | 桌面工具箱内嵌插件（uTools 风格） | 独立应用 / Web 面板 |
| 主题 | 明净浅色 · 内容优先（macOS 式） | 深色终端 / Web 面板多彩 |
| 技术栈 | Tauri 2 + Vue3 + Rust（轻量原生） | Electron / Qt / Web |
| 功能边界 | 8 项核心功能，不做网站/数据库/计划任务 | 1Panel 功能大而全 |
| 用户场景 | 开发者快速连接服务器执行命令/传文件/看监控 | 运维人员全面管理服务器集群 |

**结论**：patchyBox SSH 工具应聚焦「轻量、快速、够用」，不追求 1Panel 的全面性，而是做好终端 + 文件 + 监控 + 常用管理操作的体验，与 patchyBox 整体「明净浅色」设计语言保持一致。
