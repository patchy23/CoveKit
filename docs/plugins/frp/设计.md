# FRP 客户端配置与凭证

## Token 来源

认证方式为 `token` 时，可手工输入，也可通过公共凭证选择器选择或新建 API Token 凭证。手工 Token 沿用原有配置文件明文保存方式；选择凭证后不回显或复制秘密到前端。已有手工配置不自动迁移。

凭证引用写入 `auth.token`，格式为 `{{ .Envs.COVEKIT_FRP_TOKEN_<凭证标识的 UTF-8 小写十六进制> }}`。这是 FRP 原生环境变量模板中的保留命名空间，不包含秘密。普通手工 Token 和用户自有模板保持原语义。

含凭证引用的档案由 CoveKit 启动或校验：Rust 解析 Vault，生成只含运行模板的临时 TOML，通过该子进程环境注入已转义的 Token。不会把 Vault 明文写入档案、备份、临时配置或 IPC；进程输出按实际 Token 脱敏后再发往前端。临时配置由本次运行/校验负责清理。独立运行原档案不会自动访问 CoveKit 凭证库。

凭证缺失、密钥不可用、类型不符或引用损坏时，启动/校验明确失败，不回退为空 Token。`tokenSource` 与 Token 互斥；表单显式选择凭证或输入 Token 时移除外部来源，未编辑的外部来源保留。OIDC 的参数继续在源码模式维护。

## 引用生命周期

- 引用随 TOML 复制、重命名，无独立凭证绑定表。切换凭证或更新凭证内容后，重启进程才会生效。
- 凭证删除前由 FRP 自报当前可见档案引用；读取或解析失败上报未知，不当作零引用。软删除档案的历史备份不计入活动引用。
- 数据包的配置内容声明凭证依赖；导入需包含被引用凭证，合并按凭证身份映射改写模板。元数据单独导出不携带配置或秘密。

## 编辑与运行

页面左侧为紧凑档案列表，右侧顶部集中启停、校验与保存；配置/日志导航、表单/源码切换和客户端选择合并在下一行，空间不足时换行。表单按实际容器宽度布局：宽度至少 640px 时，连接、认证和折叠的更多配置占左栏，代理列表占右栏；窄窗口改为单栏。内容靠左排列、最大宽度 1120px；分区保留 12px 内边距，代理之间使用分隔线，保持小号控件。启停与重启使用同尺寸描边文字按钮。连接端口与远端访问端口使用不同名称，避免混淆控制连接和对外转发入口。

客户端下载默认列出最近 10 个上游版本；选择“指定历史版本”可输入完整版本号（如 `0.60.0`，也接受 `v0.60.0`），不依赖版本列表查询成功。下载沿用官方发行资产与现有安装流程；版本不存在或缺少当前平台资产时显示下载错误，上游缺少校验文件时显示未强校验提示。安装后由档案选择对应客户端，不自动更换运行中的版本。

表单和源码共用保存状态。未保存时先保存再切换模式、校验或启动，避免对旧磁盘配置执行操作；修改后清除旧校验结论。运行中的配置保存后需重启生效。进程仍有 PID 时，即使连接状态为错误，也保留停止入口。

左侧列表的状态、PID 与错误原因统一取当前运行快照；新快照未携带错误时清除旧提示。重新启动或连接恢复后不继续显示上次异常，历史错误仍保留在日志中。

表单按字段合并，保留 TLS 证书等未覆盖的嵌套字段。端口必须为 1–65535 的整数。表单保存仍会重建 TOML 并丢失注释，需保留注释时使用源码模式。

后台控制台通过 `[frp]` 前缀记录启停请求、进程创建、连接成功、停止、异常退出及启动前失败。子进程告警、错误和标准错误输出在脱敏后同步到后台；每个流最多同步前 20 行普通输出，用于排查没有等级前缀的启动错误，后续普通输出只发送页面。状态轮询不重复打印。这是控制台诊断，不代表已提供日志文件落盘或轮转。

上游依据：[配置模板](https://gofrp.org/zh-cn/docs/features/common/configure/)、[Token 认证及 tokenSource 互斥](https://gofrp.org/zh-cn/docs/features/common/authentication/)。功能范围继续受[当前产品裁决](../../standards/07-产品需求.md#当前有效范围裁决)约束。
