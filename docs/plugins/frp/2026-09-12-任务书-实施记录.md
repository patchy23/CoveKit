## 12. 实施记录（2026-09-12）

契约与本文一致（17 条 IPC 命令名、入参、返回结构、数据表、设置项、状态机判定规则均未改动）。落地文件：

**Rust（`src-tauri/src/plugins/frp/`）**

| 文件 | 职责 |
| ---- | ---- |
| `mod.rs` | 门面：17 条命令 + 设置读取（`app.tools.frp`）+ 元数据落库（`frp.db` 的 `profile_meta`）+ 命令入库与路由分发 |
| `models.rs` | 全部 IPC 数据结构（serde camelCase）、TOML 文本 ⇄ JSON 解析、注释检测、档案元信息解析（`serverAddr` / 代理计数） |
| `binary.rs` | frpc 定位（设置项 → 工具下载目录 → PATH → 常见位置）、上游版本查询、下载安装（镜像前缀 + SHA256 校验 + 系统工具解压） |
| `profile.rs` | 档案文件读写、文件名校验（防路径穿越）、`.bak` 轮转、内置模板、新建 / 复制 / 重命名 / 软删（`.trash/`） |
| `verify.rs` | `frpc verify` 调用与输出解析（行列号）、`clean_line`（剥 ANSI + 敏感值打码） |
| `runtime.rs` | 进程启停与状态机（`stopped/starting/running/error` + 兜底超时）、日志推送、退出清理 |

**前端（`src/plugins/frp/`）**

- `index.ts`（工具 manifest + 4 项设置）、`contracts.ts` / `ipc.ts`（与 Rust `models.rs` 逐字段同步）
- `FrpWorkbench.vue`：工作台（左侧档案列表 + 右侧详情/引导卡，未保存改动拦截切换）
- `profile/`：`ProfileSidebar` / `ProfileDetail` / `ProfileFormEditor` / `ProfileSourceEditor` / `ProfileNameDialog` / `ProfileRemarkDialog` / `ProxyEntryCard` + `useFrpProfiles` / `useProfileEditor` / `frpForm`（含单测）
- `runtime/`：`RuntimeLogPanel` + `frpStatus`（含单测）/ `useFrpRuntime`（事件驱动 + 5 秒轮询兜底）
- `binary/`：`BinarySetupCard` + `useFrpBinary`

**与任务书的偏差（2 处，均为简化，契约未受影响）**

1. 未单设 `index.vue` 薄壳：工具注册直接懒加载 `FrpWorkbench.vue`（少一层转发，与 database 插件写法一致）。
2. 下载源只提供单一「镜像前缀」设置项（GitHub 原站 + 可选前缀），未做多源列表。

**依赖**：新增直接依赖 `toml`（用于 TOML 文本 ⇄ JSON 双向转换，此前仅作间接依赖存在）。
下载与校验复用已有 `reqwest` / `sha2` / `hex`；解压复用系统工具（Windows `Expand-Archive`、其它平台 `tar`），未引入压缩库。
