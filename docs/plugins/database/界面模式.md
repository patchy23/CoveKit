# 数据库工作台 · 界面模式

## 当前工作台布局与密度

左侧连接与对象树、中间页签工作区、右侧可折叠摘要。SQL 新建入口固定在页签栏末端，页签过多时收纳；基础控件优先 xs，工具栏 compact，间距和颜色只用公共 tokens。高级配置收起，避免连接表单堆叠多层大面板。

连接表单包含类型、地址、端口、默认库、公共凭证选择及手填入口。密码不回填；留空保留，清空独立表达。生产默认只读；agent 类型立即显示驱动依赖；SQLite 测试不创建文件，新路径在连接时创建。

SQL 工具栏提供当前语句/选区执行、全部执行、取消、事务、格式化、文件、保存、测试模板。执行 gutter 紧邻行号，不与代码形成大空白。补全交给 CodeMirror 方言与别名解析，按真实表按需加载列。

编辑状态按页签身份保存，撤销、选区和滚动不串页；关闭即释放缓存。草稿恢复只还原文档和目标，结果缓存有预算。关闭活动事务或运行查询必须先处理，不能静默断开。

## 数据库管理功能模式

表数据使用服务端分页，额外一行判断下一页，不依赖估算计数。首次加载、空表、失败、截断分别显示；精确统计独立按钮并可取消。筛选支持多个 AND、NULL、IN、范围和排序，实际 SQL 与参数可查看。

行编辑在紧凑弹窗预览和提交，只允许有主键及完整原值的单表；错误保留输入。CSV 导入先预览和映射，再事务提交，可取消。加载结果导出与完整只读导出明确区分，显示行数、截断和重新查询语义。

结果使用类型化值，NULL、文本 NULL、空串和二进制可识别。网格截断不代表完整结果；脚本和存储过程多个结果集可切换，部分成功与错误保留。历史显示实际目标与结果状态。

Redis 使用独立键浏览界面，支持 SCAN 继续、加载更多和有界值预览。只读、驱动未实现、依赖缺失等状态必须解释原因，不能只留下无响应按钮。

## 验证要求

业务回归使用真实状态域和可控 IPC，覆盖首次加载、倒序请求、关闭迟到响应、跨库同名对象、保存时切页和独立撤销。真实数据库验证类型、事务、取消、分页与参数绑定；真实 UI 另验证点击、键盘、缩窗与缩放，不能把 mock 单测作为桌面验收。

具体契约与限制见[数据库设计](设计.md)。
