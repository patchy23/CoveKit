# database · 数据库工具设计

工作台面向个人开发和测试。MySQL、PostgreSQL、SQLite、Redis 使用成熟原生驱动；Oracle 通过独立 agent 协议适配。驱动文件存在、协议兼容和数据库连通性是三个不同状态。

## 功能与支持边界

| 能力 | MySQL / PolarDB | PostgreSQL | SQLite | Redis | Oracle agent |
| --- | --- | --- | --- | --- | --- |
| 保存、测试、连接、断开、公共凭证 | 原生 | 原生 | 本地文件 | ACL / TLS | 依赖兼容 agent |
| 对象范围 | 数据库 | 数据库 + schema | main | 配置的 db 索引 | 用户/schema |
| 查询结果 | 多结果集 | RETURNING | RETURNING / trigger | 独立命令模型 | 类型化协议 |
| 独立 SQL 页签事务 | 支持 | 支持 | 支持 | 不提供关系库事务按钮 | 会话独立，不展示未验证的事务按钮 |
| 参数化筛选、单表编辑、CSV 导入 | 支持 | 支持 | 支持 | 不适用 | 缺少参数绑定时明确拒绝 |
| 完整查询流式导出 | 支持 | 支持 | 支持 | 不适用 | 当前不提供 |
| 文件、草稿、历史、收藏 | 支持 | 支持 | 支持 | 可保存命令文档 | 支持文档能力 |
| EXPLAIN / 测试数据模板 | 支持 | 支持 | 支持 | 不适用 | 权限和协议未明确前禁用 |

不新增数据库类型、ER 图、结构同步、DBA 监控、团队共享或数据库专属 SSH 隧道。SSH 隧道使用 SSH 模块公开能力创建本地端口，再连接该端口。单表编辑不允许修改任意 JOIN/聚合结果，也不承诺批量数据修复能力。

## 代码与调用边界

前端 DatabaseWorkbench.vue 经 useDatabase.ts 装配 connection、catalog、workspace、library 四个状态域。跨域使用显式端口；contracts.ts 与 Rust models.rs 同步，ipc.ts 统一调用命令。Rust mod.rs 经模块宏装配，drivers 管理连接及工作会话，catalog 提供执行、元数据、分页、参数绑定和导入导出，store 管理本地持久化。

CodeMirror 6 是唯一编辑器基座，SQL 方言、补全和语句执行 gutter 属于插件。SQL 范围使用 sqlparser 方言 tokenizer，风险分析使用 AST 允许列表；CSV 使用 csv crate。原生驱动复用 mysql_async、tokio-postgres、rusqlite、redis。dbx 的既有树层级和图标作为参考，不引入其整套状态和秘密存储。

## 连接、凭证与恢复

配置通过唯一 DataContext 下的 PluginDb 保存，迁移只追加。连接引用公共 Vault 的 credentialId，秘密只在后端解析。手填密码保存时进入公共凭证库；Redis 无用户名时可用单 token 凭证。共享凭证用户名改变后要求重新保存连接，避免旧目标与新身份混用。

旧密码依次执行公共库写入、回读比较、保存引用。写凭证后配置保存失败时，重试按来源标记和完整字段匹配复用，旧密文保留供恢复。修改或删除连接不会自动删除共享凭证；引用提供者登记实际使用者。清空密码是显式操作，空输入仍保留旧值。导入不携带秘密，credential_pending 要求重新认证，不能沿旧 id 误用密码。

连接建立使用后端 deadline 和 generation，断开、删除、重新配置使旧建连失效；迟到成功会话必须关闭。测试结果绑定表单快照，编辑或关闭后不展示过期结果。生产环境默认只读，解除只读必须主动选择。SQLite 测试只读打开已有文件，新路径保存后连接时创建；工作 SQL 和连接建立使用阻塞任务，慢查询支持 interrupt。

## SQL 工作会话与执行

每个 SQL 页签拥有独立物理会话，按连接 id + workspace id 定位。同页串行，跨页可并发，最多 32 个工作会话。执行 scope 包含 database/schema，事务中禁止切换目标。工具关闭和应用退出经既有生命周期协调入口清理。

流程为：冻结 SQL/目标、后端预检、必要时确认、校验绑定 SQL/目标/配置/请求的短期票据、执行并等待协议终态、回填同一页签。迟到结果不得复活关闭页签。只读连接拒绝未知写语法，原生会话另使用数据库只读保护；高危 DDL 和无条件写入需要确认。

SQL 中切换数据库、search_path、认证或 autocommit 的入口受限，目标切换走控件。MySQL 可执行版本注释拒绝执行；DELIMITER/SPOOL 是客户端指令，不做静默拆分。Oracle PL/SQL 整块发送，SQLite trigger 内部语句不单独拆开。

事务状态与结果分开：部分成功保留已完成结果，提交失败显示结果未知。MySQL CALL 每个结果集记录原语句索引，不把第二个结果当作后续 SQL。

## 取消、超时与资源责任

| 驱动 | 取消方式 |
| --- | --- |
| MySQL | 实际执行连接 id + 独立控制连接 KILL QUERY |
| PostgreSQL | 实际 client 的 CancelToken，保持 TLS 一致 |
| SQLite | 工作连接 InterruptHandle |
| agent | 对应 session 的 cancel_session |
| Redis | 不能撤销已发送命令，停止等待和写入结果未知明确区分 |

取消响应只表示请求已发送，执行通道决定终态。SQL 默认 30 秒，超时后取消并等待收尾，无法确认则关闭会话。表操作同样登记真实句柄：单次查询 30 秒、导入和批量操作总计 120 秒，提交和回滚另设有限等待。取消锁在归还连接前阻止迟到取消误伤后续查询；提交发出后不能伪称已回滚。

## 类型化结果与预算

DbValue 区分 null、text、integer、decimal、float、boolean、temporal、json、binary。数值保持字符串，二进制为 hex；展示与复制原值分离，解码失败不能变成 NULL。空结果保留列名，每条语句记录影响行数、截断和错误。

| 资源 | 边界 |
| --- | --- |
| SQL | 1 MiB、500 条语句 |
| 网格 | 默认 1000 行，可选至 100000；脚本累计约 8 MiB |
| MySQL 结果集 | 最多保留 500 个，超出仍收尾协议并明确报错 |
| 表浏览 | 每页 1–500 行，额外一行判断 hasMore |
| 前端缓存 | 约 64 MiB，先释放非活动页结果，保留文档与事务 |
| 草稿 | 50 页、单页 1 MiB、合计 8 MiB |
| CSV 导入 | UTF-8/BOM、16 MiB、10000 行、512 列、预览 20 行 |
| 单元格编辑 | 1 MiB，必须有完整原值 |
| 完整导出 | 流式写入、单行 16 MiB、缓冲 256 KiB |
| agent | 有界队列和待响应表，请求 2 MiB、帧 16 MiB |

预算限制保留和传输，不代表可以丢弃未完成协议。达到展示上限仍收尾，不能给任意 SQL 偷加 LIMIT 或取消有副作用的语句。

## 对象树、表浏览与编辑

MySQL 按库分层，PG 按库/schema，Oracle 根下为 schema，SQLite 根下为对象，Redis 为独立键模型。对象页签身份包含连接、库、schema、对象名，缓存和请求归属一致；刷新后的旧响应不覆盖新状态。

有主键时追加稳定排序，pageSize+1 判断下一页；无主键提示顺序可能变化。精确 COUNT 单独触发，不阻塞首页。服务端支持最多 20 个 AND 条件、NULL、IN、范围和排序；列名校验真实结构，值只走绑定，预览展示实际 SQL 和参数。

表数据页与可确认来源的单表 SQL 结果支持双击或 F2 就地编辑，修改先留在页签内存，手动“保存并提交”才写入。保存使用独立短事务，不加入 SQL 页现有事务；活动事务须先结束再重新查询。刷新、重查和关闭必须保护未保存修改，应用退出前要求用户处理草稿。保存后重新读取数据库最终值，SQL 结果要求手动重新查询；提交结果未知时禁止原样重试。

SQL 结果必须包含全部真实列且不重名，JOIN、聚合、CTE、脚本和列别名不开放编辑。执行过可能改变名称解析的临时表语句、动态 SQL 或函数调用后，该工作会话不再提供编辑来源；可新开 SQL 页或从表数据页编辑。来源通过 QueryResult.editTarget 返回实际连接、库、schema 和表名，不从当前编辑器文本猜测。MySQL/PolarDB 批量保存仅支持 InnoDB 表；Redis 与 Oracle agent 不提供此网格事务入口。

更新和删除要求真实主键与完整原行，采用原值并发校验；MySQL 文本比较区分大小写和尾空格。一批最多 500 行、一个事务，影响 0 行或超过 1 行按冲突回滚。新增行可省略字段使用默认值。

## 文件、草稿、历史与 CSV

SQL 文件按 UTF-8 打开和另存。草稿保存文档、标签、目标、选区，不保存结果或活动事务；恢复不连接、不执行。关闭内部页签移除其恢复草稿；关闭工具先保护运行中任务和事务，再写草稿，失败可见。

历史保存实际 database/schema、耗时、成功/失败/部分完成/取消/未知状态，保留最近 300 条、显示 100 条。应用历史只打开目标文档，连接已删除时要求选择目标。测试数据模板只生成有限行数的新建表 SQL，可审阅、收藏和复用。

已加载结果导出明确筛选行数及截断；完整导出独立执行一条只读查询，读取新的时间点，不保证与网格同一快照。临时文件 flush/sync 后原子替换；失败和取消清理本任务临时文件。CSV/TSV 用反斜线 N 表示 NULL，文本反斜线前缀转义；空串、文本 NULL 和二进制保持区分，列头和值均正确引用。

CSV 导入提交绑定预览文件指纹；内容改变需重新预览。列映射显式选择，任一行失败整批回滚并指出行号，不猜编码、不默认覆盖整张表。

## Redis 与 agent

Redis 使用 SCAN cursor 去重和继续空批次，可加载更多。预览有字节/条数限制，非 UTF-8 值显示 hex，不能安全往返的键名明确拒绝。ACL、TLS、db 索引实际传给驱动，SELECT/AUTH/HELLO 不污染共享会话。

agent 必须是兼容可执行程序，通过版本和多会话握手；JAR 不视为可直接运行的驱动。对象、列和结果 shape 错误必须报协议失败。进程创建竞争不能覆盖已有客户端；队列、帧、等待时间有界。Oracle 的数据库、驱动分发和平台依赖需单独验证，协议夹具不能替代实机验收。
